# راهنمای جلسه با Claude

## چرخهٔ هر مبحث (یک بلوک ۹۰ دقیقه‌ای)
1. **۵ دقیقه:** بگو `جزوه بساز: <مبحث امروز>` (اگر هنوز ساخته نشده).
2. **۳۵ دقیقه:** جزوه را بخوان. مثال‌ها را **قبل از** دیدن راه‌حل خودت امتحان کن. هر جا گیر کردی همان لحظه بپرس.
3. **۳۰ دقیقه:** تمرین‌های آخر جزوه، بدون باز کردن جواب‌ها.
4. **۱۵ دقیقه:** بگو `آزمونم کن: <مبحث>`. جواب‌ها را بفرست تا تحلیل شود.
5. **۵ دقیقه:** بگو `پایان جلسه` تا پیشرفت و دفتر خطا ذخیره و push شود.

## دستورها
| بگو | Claude چه می‌کند |
|---|---|
| `جزوه بساز: <مبحث>` | جزوهٔ مبحث را با سؤال واقعی کنکور می‌سازد و در `tutor/notes/` می‌گذارد |
| `نفهمیدم: <بخش>` | همان را از زاویهٔ دیگر و با مثال ساده‌تر توضیح می‌دهد |
| `آزمونم کن: <مبحث>` | ۵ تا ۱۰ تست، یکی‌یکی، بعد تشخیص علت خطا |
| `این سؤال: <عکس یا متن>` | حل قدم‌به‌قدم + نکته‌ای که باید می‌دانستی |
| `آزمون هفتگی` | جمعه: آزمون از مباحث هفته + دفتر خطا |
| `پایان جلسه` | به‌روزرسانی `progress.md` و `errors.md` و push |

## دو قاعده که نتیجه را تعیین می‌کند
- **خواندن ≠ بلد بودن.** جزوه‌ای که روان خوانده شد ولی تمرینش حل نشد، یاد گرفته نشده. معیار فقط درصد تست است.
- **Claude هم ممکن است اشتباه کند.** اگر جوابی با کلید دفترچهٔ کنکور نخواند، بگو تا بررسی شود.
