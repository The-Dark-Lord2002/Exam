# جزوه ۱ ساختمان داده: تحلیل پیچیدگی، نمادهای مجانبی، روابط بازگشتی، تحلیل سرشکن

> **چرا این مبحث؟** در کنکور ارشد کامپیوتر ۱۳۹۸ تا ۱۴۰۴، **۱۱ سؤال** از این مبحث آمده و **۸ تا از آن‌ها فقط در ۱۴۰۲ تا ۱۴۰۴** بوده است. یعنی این روزها هر سال ۲ تا ۳ سؤال. پایهٔ کل درس الگوریتم هم همین است.
>
> **هدف این جزوه:** بعد از آن باید بتوانی (۱) دو تابع را از نظر رشد مقایسه کنی، (۲) تعداد اجرای حلقه‌ها را بشماری، (۳) هر رابطهٔ بازگشتی کنکوری را با یکی از ۵ ابزار حل کنی.

## بخش ۱: نمادهای مجانبی

### شهود
وقتی n خیلی بزرگ است، فقط **سریع‌ترین جملهٔ رشد** مهم است و ضریب‌ها مهم نیستند.
مثلاً $3n^2 + 100n + 7$ برای n بزرگ تقریباً مثل $n^2$ رفتار می‌کند.

| نماد | معنی ساده | تعریف |
|---|---|---|
| $f = O(g)$ | f **حداکثر** هم‌اندازهٔ g رشد می‌کند (≤) | $\exists c, n_0: f(n) \le c\,g(n)\ \ \forall n \ge n_0$ |
| $f = \Omega(g)$ | f **حداقل** هم‌اندازهٔ g رشد می‌کند (≥) | $f(n) \ge c\,g(n)$ |
| $f = \Theta(g)$ | **دقیقاً** هم‌اندازه (=) | هم $O$ هم $\Omega$ |
| $f = o(g)$ | **اکیداً** کندتر (<) | $\lim f/g = 0$ |
| $f = \omega(g)$ | **اکیداً** سریع‌تر (>) | $\lim f/g = \infty$ |

### نردبان رشد (حفظ کن)

$$1 \;<\; \log\log n \;<\; \log n \;<\; (\log n)^{k} \;<\; n^{\varepsilon} \;<\; n \;<\; n\log n \;<\; n^{2} \;<\; n^{k} \;<\; 2^{n} \;<\; 3^{n} \;<\; n! \;<\; n^{n}$$

(اینجا $k$ ثابت دلخواه و $\varepsilon$ هر عدد مثبت کوچک مثل ۰٫۰۱ است.)

### ابزار اصلی مقایسه: از دو طرف لگاریتم بگیر
اگر نمی‌دانی کدام بزرگ‌تر است، $\log$ هر دو را مقایسه کن.

**مثال:** کدام بزرگ‌تر است، $n^{\log n}$ یا $(\log n)^n$؟
- $\log(n^{\log n}) = \log^2 n$
- $\log((\log n)^n) = n \log\log n$
- $n\log\log n$ خیلی بزرگ‌تر از $\log^2 n$ است، پس $(\log n)^n$ بزرگ‌تر است.

> ⚠️ **محدودیت این روش:** اگر لگاریتم‌ها **اکیداً** رشد متفاوت داشته باشند (یکی $o$ دیگری باشد)، نتیجه درست است. اگر لگاریتم‌ها فقط در ضریب فرق کنند، خود توابع ممکن است Θ نباشند. مثال: $\log(4^n) = 2\log(2^n)$، ولی $4^n \ne \Theta(2^n)$.

### تله‌های تستی (این‌ها را در کنکور می‌پرسند)
1. **مبنای لگاریتم مهم نیست:** $\log_2 n = \Theta(\log_{10} n)$. ولی **مبنای توان مهم است:** $2^n \ne \Theta(3^n)$.
2. $2^{n+1} = \Theta(2^n)$ (ضرب در ۲)، ولی $2^{2n} = 4^n \ne O(2^n)$.
3. $\log(n!) = \Theta(n\log n)$ (از تقریب استرلینگ). این خیلی زیاد می‌آید.
4. $n^{\log_b a} = a^{\log_b n}$. مثلاً $3^{\log_2 n} = n^{\log_2 3} \approx n^{1.58}$.
5. $\sum_{i=1}^{n} \frac{1}{i} = \Theta(\log n)$ (سری هارمونیک) و $\sum_{i=1}^{n} i^k = \Theta(n^{k+1})$.
6. $\sum_{i=0}^{\log n} 2^i = \Theta(n)$. **در سری هندسی، بزرگ‌ترین جمله غالب است.**
7. اگر $f = O(g)$، الزاماً $2^f = O(2^g)$ **نیست**. مثال: $2n = O(n)$ ولی $4^n \ne O(2^n)$.

## بخش ۲: شمارش حلقه‌ها

**قاعده:** هزینهٔ حلقه‌های تودرتو = جمع روی حلقهٔ بیرونی، از تعداد اجرای حلقهٔ درونی.

| کد | تعداد اجرا | چرا |
|---|---|---|
| `for(i=1;i<=n;i++) for(j=1;j<=i;j++)` | $\Theta(n^2)$ | $1+2+\dots+n = n(n+1)/2$ |
| `for(i=1;i<=n;i*=2)` | $\Theta(\log n)$ | i دو برابر می‌شود |
| `for(i=2;i<=n;i=i*i)` | $\Theta(\log\log n)$ | $i = 2^{2^k}$، پس $2^k = \log n$ |
| `for(i=1;i<=n;i*=2) for(j=1;j<=i;j++)` | $\Theta(n)$ | $1+2+4+\dots+n < 2n$ (هندسی) |
| `for(i=1;i<=n;i++) for(j=1;j<=n;j+=i)` | $\Theta(n\log n)$ | $\sum n/i = n \cdot H_n$ (هارمونیک) |
| `for(i=1;i<=n;i++) for(j=1;j*j<=i;j++)` | $\Theta(n^{1.5})$ | $\sum \sqrt{i} = \Theta(n^{1.5})$ |

> ⚠️ **تله:** وقتی حلقهٔ درونی به i وابسته است، **ضرب نکن، جمع بزن.** ضرب کردن حلقهٔ چهارم جدول را $n \log n$ نشان می‌دهد، در حالی که جواب درست $n$ است.

## بخش ۳: روابط بازگشتی، ۵ ابزار

### نقشهٔ تصمیم (اول این را نگاه کن)
| شکل رابطه | ابزار |
|---|---|
| $T(n) = aT(n/b) + f(n)$ | **۳.۱ قضیهٔ اصلی** |
| تقسیم‌های **نامساوی**: $T(\alpha n) + T(\beta n) + \dots$ | **۳.۲ درخت بازگشت** یا **۳.۳ آکرا-بازی** |
| $T(\sqrt{n})$ دارد | **۳.۴ تغییر متغیر** |
| $T(n-1)$ یا $T(n-c)$ دارد | **۳.۵ باز کردن (جایگذاری)** |

### ۳.۱ قضیهٔ اصلی (Master Theorem)

برای $T(n) = aT(n/b) + f(n)$، اول $c = \log_b a$ را حساب کن و $f(n)$ را با $n^c$ مقایسه کن.

| حالت | شرط | جواب |
|---|---|---|
| ۱: برگ‌ها غالب‌اند | $f(n) = O(n^{c-\varepsilon})$ (چندجمله‌ای کوچک‌تر) | $\Theta(n^c)$ |
| ۲: مساوی | $f(n) = \Theta(n^c \log^k n)$ | جدول زیر را ببین |
| ۳: ریشه غالب است | $f(n) = \Omega(n^{c+\varepsilon})$ و $a f(n/b) \le \delta f(n)$ با $\delta<1$ | $\Theta(f(n))$ |

**حالت ۲ گسترده** (در کنکور حالت‌های $k$ منفی را هم می‌پرسند):

| مقدار k | جواب |
|---|---|
| $k > -1$ | $\Theta(n^c \log^{k+1} n)$ |
| $k = -1$ | $\Theta(n^c \log\log n)$ |
| $k < -1$ | $\Theta(n^c)$ |

**مثال‌ها:**
- $T(n) = 2T(n/2) + n$: $c = 1$، $f = n^1 \log^0 n$، پس $k=0$ و جواب $\Theta(n\log n)$. (مرتب‌سازی ادغامی)
- $T(n) = 8T(n/2) + n^2$: $c = 3$، $f$ کوچک‌تر است، پس $\Theta(n^3)$.
- $T(n) = T(n/2) + 1$: $c = 0$، $k=0$، پس $\Theta(\log n)$. (جستجوی دودویی)
- $T(n) = 2T(n/2) + n/\log n$: $c=1$، $k=-1$، پس $\Theta(n\log\log n)$.

> ⚠️ **تله:** $T(n) = 2T(n/2) + n\log n$ حالت ۳ **نیست**. $n\log n$ فقط به اندازهٔ یک $\log$ بزرگ‌تر از $n$ است، نه به اندازهٔ یک توان چندجمله‌ای $n^{\varepsilon}$. این حالت ۲ با $k=1$ است و جواب $\Theta(n \log^2 n)$.

### ۳.۲ درخت بازگشت
هزینهٔ هر سطح را حساب کن و در تعداد سطح‌ها جمع بزن.

**مثال:** $T(n) = T(n/3) + T(2n/3) + n$
- هزینهٔ هر سطح حداکثر $n$ است (چون $n/3 + 2n/3 = n$).
- عمق درخت $\log_{3/2} n$ است.
- جواب: $\Theta(n\log n)$.

**قاعدهٔ سریع** برای $T(n) = T(\alpha n) + T(\beta n) + \Theta(n)$:
- اگر $\alpha + \beta < 1$: جواب $\Theta(n)$ است (هزینهٔ سطح‌ها هندسی کم می‌شود).
- اگر $\alpha + \beta = 1$: جواب $\Theta(n \log n)$ است.
- اگر $\alpha + \beta > 1$: جواب از $n\log n$ بزرگ‌تر است؛ از آکرا-بازی استفاده کن.

### ۳.۳ آکرا-بازی (Akra–Bazzi): ابزار نهایی تقسیم‌های نامساوی

برای $T(x) = \sum_i a_i\, T(b_i x) + g(x)$:
1. عدد $p$ را طوری پیدا کن که $\sum_i a_i\, b_i^{\,p} = 1$.
2. $\displaystyle T(x) = \Theta\!\left(x^p \left(1 + \int_1^x \frac{g(u)}{u^{p+1}}\, du\right)\right)$

**انتگرال‌هایی که لازم داری:**
- $\int \frac{du}{u} = \ln x$
- $\int \frac{du}{u \ln u} = \ln\ln x$
- $\int u^{-1-\varepsilon}\, du$ = عدد ثابت (همگرا)

### ⭐ سؤال واقعی: کنکور ارشد کامپیوتر ۱۴۰۴، سؤال ۵۶

> فرض کنید $T(x) = 2T\!\left(\frac{x}{2}\right) + \frac{8}{9}T\!\left(\frac{3x}{4}\right) + \Theta\!\left(\frac{x^2}{\log x}\right)$. کدام مورد درست است؟
> 1. $\Theta(x^2 \log x)$
> 2. $\Theta(x^2 / \log x)$
> 3. $\Theta(x^2 \log\log x)$
> 4. $\Theta(2\log x - \log\log x)$

**اول خودت امتحان کن (۴ دقیقه)، بعد راه‌حل را باز کن.**

<details>
<summary>راه‌حل</summary>

**مرحلهٔ ۱: پیدا کردن p.** تقسیم‌ها نامساوی‌اند، پس قضیهٔ اصلی کار نمی‌کند و از آکرا-بازی استفاده می‌کنیم.

$$2\left(\tfrac12\right)^p + \tfrac{8}{9}\left(\tfrac34\right)^p = 1$$

$p = 2$ را امتحان کن: $2 \cdot \frac14 + \frac89 \cdot \frac{9}{16} = \frac12 + \frac12 = 1$. پس $p = 2$.
(ترفند: عدد $\frac{8}{9}$ عمداً طوری انتخاب شده که $p=2$ جواب شود؛ اول توان $f$ را امتحان کن.)

**مرحلهٔ ۲: انتگرال.**

$$\int_1^x \frac{u^2/\log u}{u^{3}}\,du = \int_1^x \frac{du}{u\log u} = \Theta(\log\log x)$$

**مرحلهٔ ۳: جواب.** $T(x) = \Theta(x^2 \cdot \log\log x)$، یعنی **گزینهٔ ۳**.

**نکتهٔ مهم:** این دقیقاً همان «حالت ۲ با $k=-1$» قضیهٔ اصلی است. $f = x^p / \log x$ و $p$ همان توان مرزی است. پس اگر الگو را بشناسی، بدون انتگرال هم در ۳۰ ثانیه جواب را می‌گیری.
</details>

### ۳.۴ تغییر متغیر (وقتی $\sqrt{n}$ دیدی)
قرار بده $n = 2^m$ (یعنی $m = \log n$) و $S(m) = T(2^m)$.

**مثال ۱:** $T(n) = 2T(\sqrt n) + \log n$
- با تغییر متغیر: $S(m) = 2S(m/2) + m$
- طبق قضیهٔ اصلی: $S(m) = \Theta(m\log m)$
- برگرداندن به n: $T(n) = \Theta(\log n \cdot \log\log n)$

**مثال ۲:** $T(n) = T(\sqrt n) + 1$
- با تغییر متغیر: $S(m) = S(m/2) + 1$، پس $S(m) = \Theta(\log m)$
- برگرداندن به n: $T(n) = \Theta(\log\log n)$

**ترفند تقسیم:** اگر رابطه به شکل $T(n) = \sqrt n\, T(\sqrt n) + n$ بود، اول دو طرف را بر $n$ تقسیم کن. با $R(n) = T(n)/n$ به $R(n) = R(\sqrt n) + 1$ می‌رسی.

### ۳.۵ کم‌شونده‌ها ($T(n-1)$): باز کن و جمع بزن
| رابطه | جواب | چرا |
|---|---|---|
| $T(n) = T(n-1) + 1$ | $\Theta(n)$ | n بار ۱ |
| $T(n) = T(n-1) + n$ | $\Theta(n^2)$ | $\sum i$ |
| $T(n) = T(n-1) + \log n$ | $\Theta(n\log n)$ | $\log(n!)$ |
| $T(n) = T(n-1) + 1/n$ | $\Theta(\log n)$ | هارمونیک |
| $T(n) = 2T(n-1) + 1$ | $\Theta(2^n)$ | هانوی |
| $T(n) = T(n-1) + T(n-2)$ | $\Theta(\varphi^n)$ با $\varphi \approx 1.618$ | فیبوناچی |

## بخش ۴: تحلیل سرشکن (Amortized)

### شهود
بعضی عمل‌ها گاهی گران‌اند ولی **کم پیش می‌آیند**. میانگین هزینه روی **بدترین دنبالهٔ n عمل** را حساب می‌کنیم.

> ⚠️ این تحلیل **احتمالاتی نیست** و تحلیل حالت متوسط هم نیست. برای بدترین دنباله تضمین می‌دهد.

### سه مثال کلاسیک (همهٔ تست‌ها از همین‌هاست)

**۱. آرایهٔ پویا با دوبرابر کردن:** وقتی آرایه پر شد، دو برابر می‌شود و همه کپی می‌شوند.
- هزینهٔ کل n درج: $n$ (خود درج‌ها) $+ (1 + 2 + 4 + \dots + n)$ (کپی‌ها) $< 3n$.
- پس هزینهٔ سرشکن هر درج $O(1)$ است.

> ⚠️ **تله:** اگر به جای دو برابر شدن، **مقدار ثابتی** اضافه شود (مثلاً هر بار ۱۰۰ خانه)، کپی‌ها $\Theta(n^2)$ می‌شوند و هزینهٔ سرشکن هر درج $\Theta(n)$.
>
> ⚠️ **تلهٔ کوچک کردن:** اگر آرایه وقتی نیمه‌پر شد نصف شود، با درج و حذف متناوب درست روی مرز، هر عمل $\Theta(n)$ هزینه دارد. راه درست این است که وقتی ربع‌پر شد نصف شود.

**۲. شمارندهٔ دودویی:** هر عمل increment چند بیت را عوض می‌کند.
- بیت i هر $2^i$ عمل یک بار تغییر می‌کند، پس کل تغییرها در n عمل $\sum n/2^i < 2n$ است.
- هزینهٔ سرشکن: $O(1)$.
- **روش پتانسیل:** $\Phi$ = تعداد بیت‌های ۱. فرض کن یک increment، t بیتِ ۱ را صفر و یک بیت را ۱ کند. هزینهٔ واقعی $t+1$ است و $\Delta\Phi = 1 - t$، پس هزینهٔ سرشکن $= 2$.

**۳. پشته با MULTIPOP(k):** هر عنصر حداکثر یک بار push و یک بار pop می‌شود.
- n عمل حداکثر $2n$ هزینه دارند، پس هزینهٔ سرشکن $O(1)$.

### سه روش (اسم‌هایشان در تست می‌آید)
| روش | ایده |
|---|---|
| تجمعی (Aggregate) | کل هزینه تقسیم بر n |
| حسابداری (Accounting) | از عمل‌های ارزان «پیش‌پرداخت» بگیر تا گران‌ها را بپوشانی؛ اعتبار هیچ‌وقت منفی نشود |
| پتانسیل (Potential) | هزینهٔ سرشکن = هزینهٔ واقعی $+ \Delta\Phi$؛ با شرط $\Phi \ge \Phi_0$ |

## بخش ۵: تمرین (بدون باز کردن جواب، حداکثر ۴ دقیقه برای هر کدام)

1. $T(n) = 4T(n/2) + n^2\log n$
2. $T(n) = 3T(n/4) + n\log n$
3. $T(n) = 7T(n/2) + n^2$
4. $T(n) = T(n/2) + T(n/4) + T(n/8) + n$
5. $T(n) = \sqrt n\, T(\sqrt n) + n$
6. $T(n) = T(n-1) + \log n$
7. تعداد اجرای حلقهٔ درونی را بنویس:
   ```c
   for (i = n; i > 1; i = i / 2)
       for (j = 0; j < i; j++)
           x++;
   ```
8. کدام درست است؟
   (۱) $n^{\log n} = O((\log n)^n)$
   (۲) $(\log n)^n = O(n^{\log n})$
   (۳) هر دو Θ هم‌اند
   (۴) قابل مقایسه نیستند
9. کدام درست است؟
   (۱) $\log(n!) = \Theta(n)$
   (۲) $\log(n!) = \Theta(n\log n)$
   (۳) $\log(n!) = \Theta(n^2)$
   (۴) $\log(n!) = \Theta(\log n)$
10. یک آرایهٔ پویا هر بار که پر شود **۱۰۰ خانه** بزرگ‌تر می‌شود. هزینهٔ سرشکن هر درج در n درج متوالی چقدر است؟
11. $T(n) = 2T(n/2) + n\log n$
12. $T(n) = 2T(\sqrt n) + 1$

## 🗂 کارت خلاصه (برای جمع‌بندی فاز ۳)
- **نردبان:** $1 < \log\log n < \log n < n^\varepsilon < n < n\log n < n^k < 2^n < n! < n^n$
- **مقایسه:** از دو طرف log بگیر. $\log(n!) = \Theta(n\log n)$. مبنای log مهم نیست، مبنای توان مهم است.
- **حلقه:** حلقهٔ وابسته را جمع بزن. `i*=2` یعنی $\log n$، `i=i*i` یعنی $\log\log n$، `j+=i` یعنی هارمونیک.
- **قضیهٔ اصلی:** $c = \log_b a$. اگر $f = n^c\log^k n$: برای $k>-1$ جواب $n^c\log^{k+1}n$، برای $k=-1$ جواب $n^c\log\log n$، برای $k<-1$ جواب $n^c$.
- **تقسیم نامساوی:** اگر $\sum\alpha<1$ جواب $n$، اگر $=1$ جواب $n\log n$؛ در غیر این صورت آکرا-بازی ($\sum a_i b_i^p = 1$).
- **$\sqrt n$:** قرار بده $n = 2^m$.
- **سرشکن:** دوبرابر کردن $O(1)$ است، اضافهٔ ثابت $\Theta(n)$. شمارنده و MULTIPOP هم $O(1)$.
