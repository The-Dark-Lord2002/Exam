# فصل ۱: تحلیل پیچیدگی، نمادهای مجانبی و روابط بازگشتی

> **سهم در کنکور:** ۱۱ سؤال در ارشد ۱۳۹۸ تا ۱۴۰۴، که **۸ تای آن‌ها در ۱۴۰۲ تا ۱۴۰۴** بوده؛ یعنی این روزها هر سال ۲ تا ۳ سؤال. پایهٔ همهٔ فصل‌های بعدی هم همین است.
> **زمان مطالعه:** دو بلوک ۹۰ دقیقه‌ای (درس ۱ تا ۳، بعد درس ۴ و ۵) + ۲۵ دقیقه آزمون فصل.

## درس ۱: نمادهای مجانبی و مقایسهٔ رشد

**شهود:** برای n خیلی بزرگ فقط سریع‌ترین جمله مهم است و ضریب‌ها مهم نیستند. `3n² + 100n` مثل `n²` رفتار می‌کند.

| نماد | معنی ساده | تعریف |
|---|---|---|
| `f = O(g)` | f حداکثر هم‌اندازهٔ g رشد می‌کند (≤) | ثابت‌های `c` و `n₀` هستند که برای `n ≥ n₀`، `f(n) ≤ c·g(n)` |
| `f = Ω(g)` | حداقل (≥) | `f(n) ≥ c·g(n)` |
| `f = Θ(g)` | هم‌اندازه (=) | هم O هم Ω |
| `f = o(g)` | اکیداً کندتر (<) | `f/g → 0` |
| `f = ω(g)` | اکیداً سریع‌تر (>) | `f/g → ∞` |

### نردبان رشد
`1 < log log n < log n < (log n)ᵏ < n^ε < n < n log n < n² < nᵏ < 2ⁿ < 3ⁿ < n! < nⁿ`

### ابزار مقایسه: لگاریتم بگیر
**مثال:** `n^(log n)` یا `(log n)ⁿ`؟
لگاریتم اولی `log² n` است و لگاریتم دومی `n · log log n`. دومی خیلی بزرگ‌تر است، پس `(log n)ⁿ` بزرگ‌تر است.
⚠️ اگر لگاریتم‌ها فقط **در ضریب** فرق کنند، نتیجه نگیر: `log 4ⁿ = 2 log 2ⁿ` ولی `4ⁿ ≠ Θ(2ⁿ)`.

### تله‌ها
1. مبنای log مهم نیست (`log₂ n = Θ(log₁₀ n)`)، ولی **مبنای توان مهم است** (`2ⁿ ≠ Θ(3ⁿ)`).
2. `log n² = 2 log n = Θ(log n)` ولی `log² n = (log n)²` بزرگ‌تر است.
3. **`log(n!) = Θ(n log n)`** و `log(nⁿ) = n log n`؛ این دو Θ هم‌اند.
4. `a^(log_b n) = n^(log_b a)`؛ مثلاً `2^(log₂ n) = n`.
5. `Σ 1/i = Θ(log n)` (هارمونیک)، `Σ iᵏ = Θ(nᵏ⁺¹)`، و در سری هندسی جملهٔ بزرگ غالب است.
6. بعضی توابع **مقایسه‌ناپذیرند**؛ مثلاً اگر توان نوسان کند (مثل `n^(1+sin n)`)، نه O است نه Ω.

### تمرین درس ۱
1. `log(n!)` از چه مرتبه‌ای است؟
2. درست یا نادرست: `2ⁿ⁺¹ = Θ(2ⁿ)`؛ `2²ⁿ = O(2ⁿ)`.
3. به‌ترتیب صعودی مرتب کن: `n log n`، `n^1.5`، `2^(log₂ n)`، `(log n)¹⁰`
4. `n^(1/log₂ n)` از چه مرتبه‌ای است؟

<details>
<summary>جواب‌ها</summary>

1. `Θ(n log n)`
2. درست؛ نادرست (`2²ⁿ = 4ⁿ`).
3. `(log n)¹⁰ < 2^(log₂ n) = n < n log n < n^1.5`
4. `= 2^(log₂ n / log₂ n) = 2`، یعنی `Θ(1)`.
</details>

## درس ۲: شمردن حلقه‌ها

**قاعده:** اگر حلقهٔ درونی به i وابسته است، **ضرب نکن، جمع بزن.**

| کد | مرتبه | چرا |
|---|---|---|
| `for(i=1;i<=n;i++) for(j=1;j<=i;j++)` | `Θ(n²)` | `1+2+…+n` |
| `for(i=1;i<=n;i*=2)` | `Θ(log n)` | i دو برابر می‌شود |
| `for(i=2;i<=n;i=i*i)` | `Θ(log log n)` | `i = 2^(2ᵏ)` |
| `for(i=1;i<=n;i*=2) for(j=1;j<=i;j++)` | `Θ(n)` | `1+2+4+…+n < 2n` |
| `for(i=1;i<=n;i++) for(j=1;j<=n;j+=i)` | `Θ(n log n)` | `Σ n/i` هارمونیک |
| `i=1; while(i*i<=n) i++;` | `Θ(√n)` | |

### تمرین درس ۲
1. `for(i=n; i>1; i=i/2) for(j=0; j<i; j++) x++;`
2. `for(i=1;i<=n;i++) for(j=1;j<=i;j++) for(k=1;k<=j;k++) x++;`
3. `for(i=1;i<=n;i++) for(j=1;j<=n;j*=2) x++;`

<details>
<summary>جواب‌ها</summary>

1. `n + n/2 + n/4 + … < 2n`، پس `Θ(n)`. (ضرب کردن جواب غلط `n log n` را می‌دهد.)
2. `Σᵢ Σⱼ j = Σ i²/2 ≈ n³/6`، پس `Θ(n³)`.
3. حلقهٔ درونی به i وابسته **نیست**، پس اینجا ضرب درست است: `Θ(n log n)`.
</details>

## درس ۳: قضیهٔ اصلی (Master Theorem)

برای `T(n) = a·T(n/b) + f(n)` با `a ≥ 1` و `b > 1`:
**قدم ۱:** `c = log_b a` را حساب کن. **قدم ۲:** `f(n)` را با `n^c` مقایسه کن.

### نسخهٔ کلاسیک (سه حالت)
| حالت | شرط | جواب |
|---|---|---|
| ۱ | `f` **چندجمله‌ای کوچک‌تر** از `n^c` است: `f = O(n^(c−ε))` | `Θ(n^c)` |
| ۲ | `f = Θ(n^c)` | `Θ(n^c · log n)` |
| ۳ | `f` **چندجمله‌ای بزرگ‌تر** است: `f = Ω(n^(c+ε))`، و `a·f(n/b) ≤ δ·f(n)` با `δ<1` | `Θ(f(n))` |

⚠️ **مهم برای تست:** وقتی `f` فقط به اندازهٔ یک ضریب `log` با `n^c` فرق دارد (مثل `n log n` در برابر `n`)، در هیچ‌کدام از سه حالت کلاسیک نمی‌افتد. اگر تست بپرسد «کدام را **نمی‌توان مستقیماً** با قضیهٔ اصلی حل کرد»، منظورش همین شکاف است (سؤال ۸ آزمون فصل).

### حالت ۲ گسترده (برای پیدا کردن جواب)
اگر `f = Θ(n^c · logᵏ n)`:

| k | جواب |
|---|---|
| `k > −1` | `Θ(n^c · logᵏ⁺¹ n)` |
| `k = −1` | `Θ(n^c · log log n)` |
| `k < −1` | `Θ(n^c)` |

### مثال‌ها
| رابطه | c | جواب |
|---|---|---|
| `2T(n/2) + n` | 1 | حالت ۲: `Θ(n log n)` (مرتب‌سازی ادغامی) |
| `T(n/2) + 1` | 0 | حالت ۲: `Θ(log n)` (جستجوی دودویی) |
| `8T(n/2) + n²` | 3 | حالت ۱: `Θ(n³)` |
| `2T(n/2) + n²` | 1 | حالت ۳: `Θ(n²)` |
| `2T(n/2) + n log n` | 1 | گسترده با k=1: `Θ(n log² n)` |

### تمرین درس ۳
1. `9T(n/3) + n²`
2. `3T(n/4) + n log n`
3. `7T(n/2) + n²`
4. `2T(n/4) + √n`
5. `2T(n/2) + n/log n`
6. `4T(n/2) + n² log n`

<details>
<summary>جواب‌ها</summary>

1. `c=2`، حالت ۲: `Θ(n² log n)`
2. `c ≈ 0.79`، حالت ۳ و شرط نظم برقرار است: `Θ(n log n)`
3. `c = log₂ 7 ≈ 2.81`، حالت ۱: `Θ(n^2.81)` (استراسن)
4. `c = 1/2`، حالت ۲: `Θ(√n log n)`
5. گسترده با k=−1: `Θ(n log log n)` (در نسخهٔ کلاسیک مستقیم حل نمی‌شود)
6. گسترده با k=1: `Θ(n² log² n)` (در نسخهٔ کلاسیک مستقیم حل نمی‌شود)
</details>

## درس ۴: سایر روش‌های حل رابطهٔ بازگشتی

### نقشهٔ انتخاب ابزار
| شکل رابطه | ابزار |
|---|---|
| `aT(n/b) + f` | قضیهٔ اصلی (درس ۳) |
| تقسیم نامساوی: `T(αn) + T(βn) + …` | درخت بازگشت یا آکرا-بازی |
| `T(√n)` | تغییر متغیر |
| `T(n−1)` یا `T(n−c)` | باز کردن و جمع زدن |

### الف) درخت بازگشت
برای `T(n) = T(αn) + T(βn) + Θ(n)`:
- اگر `α+β < 1` جواب `Θ(n)` است.
- اگر `α+β = 1` جواب `Θ(n log n)` است (هزینهٔ هر سطح n و عمق `log n`).
- اگر `α+β > 1` از آکرا-بازی استفاده کن.

### ب) آکرا-بازی (ابزار نهایی تقسیم‌های نامساوی)
برای `T(x) = Σ aᵢ·T(bᵢ·x) + g(x)`:
1. عدد p را طوری پیدا کن که `Σ aᵢ · bᵢᵖ = 1`. (ترفند: اول توان g را امتحان کن.)
2. جواب `Θ( xᵖ · (1 + ∫₁ˣ g(u)/u^(p+1) du) )` است.

انتگرال‌های لازم: `∫du/u = ln x`، `∫du/(u ln u) = ln ln x`.
**نتیجهٔ عملی:** اگر `g = xᵖ · logᵏ x` باشد، همان جدول «حالت ۲ گسترده» با `c = p` جواب را می‌دهد.

### ج) تغییر متغیر (وقتی `√n` دیدی)
قرار بده `n = 2ᵐ` و `S(m) = T(2ᵐ)`.
- `T(n) = 2T(√n) + log n` تبدیل می‌شود به `S(m) = 2S(m/2) + m`، پس `S = m log m` و `T = Θ(log n · log log n)`.
- `T(n) = T(√n) + 1` تبدیل می‌شود به `S(m) = S(m/2) + 1`، پس `T = Θ(log log n)`.
- **ترفند تقسیم:** برای `T(n) = √n·T(√n) + n` اول دو طرف را بر n تقسیم کن و `R(n) = T(n)/n` بگذار.

### د) کم‌شونده‌ها
| رابطه | جواب |
|---|---|
| `T(n−1) + 1` | `Θ(n)` |
| `T(n−1) + n` | `Θ(n²)` |
| `T(n−1) + log n` | `Θ(n log n)` |
| `T(n−1) + 1/n` | `Θ(log n)` |
| `2T(n−1) + 1` | `Θ(2ⁿ)` (هانوی) |
| `T(n−1) + T(n−2)` | `Θ(φⁿ)` با `φ ≈ 1.618` (فیبوناچی) |
| `T(n−1) + 2T(n−2) + T(n−3)` | ریشهٔ معادلهٔ `x³ = x² + 2x + 1` (≈ 2.2)؛ پس **کران ساده** `3ⁿ` است |

### تمرین درس ۴
1. `T(n) = T(n/2) + T(n/4) + T(n/8) + n`
2. `T(n) = T(n/4) + T(3n/4) + n`
3. `T(n) = √n · T(√n) + n`
4. `T(n) = 2T(√n) + 1`
5. `T(n) = T(n−2) + n`

<details>
<summary>جواب‌ها</summary>

1. `1/2 + 1/4 + 1/8 = 7/8 < 1`، پس `Θ(n)`.
2. `1/4 + 3/4 = 1`، پس `Θ(n log n)`.
3. `R(n) = R(√n) + 1`، پس `R = log log n` و `T = Θ(n log log n)`.
4. `S(m) = 2S(m/2) + 1`، پس `S = Θ(m)` و `T = Θ(log n)`.
5. `n + (n−2) + (n−4) + … ≈ n²/4`، پس `Θ(n²)`.
</details>

## درس ۵: تحلیل سرشکن (Amortized)

**شهود:** میانگین هزینه روی **بدترین دنبالهٔ n عمل**. این تحلیل احتمالاتی نیست و تحلیل حالت متوسط هم نیست؛ تضمین بدترین حالت است.

| مثال | تحلیل | هزینهٔ سرشکن |
|---|---|---|
| آرایهٔ پویا با **دو برابر** شدن | کپی‌ها `1+2+4+…+n < 2n` | `O(1)` |
| آرایهٔ پویا با **اضافهٔ ثابت** (مثلاً +۱۰۰) | کپی‌ها `Θ(n²)` | `Θ(n)` |
| شمارندهٔ دودویی (فقط افزایش) | بیت i هر `2ⁱ` بار عوض می‌شود؛ جمع `< 2n` | `O(1)` |
| پشته با MULTIPOP | هر عنصر حداکثر یک push و یک pop دارد | `O(1)` |

**سه روش:**
- **تجمعی:** کل هزینه تقسیم بر n.
- **حسابداری:** عمل‌های ارزان پیش‌پرداخت می‌دهند تا عمل‌های گران پوشش داده شوند؛ اعتبار هیچ‌وقت منفی نمی‌شود.
- **پتانسیل:** هزینهٔ سرشکن = هزینهٔ واقعی + `ΔΦ`. مثلاً در شمارنده با Φ = تعداد بیت‌های ۱، هر increment هزینهٔ سرشکن ۲ دارد.

### تمرین درس ۵
1. آرایهٔ پویا هر بار که پر شد **سه برابر** می‌شود. هزینهٔ سرشکن هر درج؟
2. شمارندهٔ k بیتی که هم increment و هم decrement دارد. هزینهٔ سرشکن هر عمل در بدترین دنباله؟

<details>
<summary>جواب‌ها</summary>

1. `O(1)` (هر ضریب ثابت بزرگ‌تر از ۱ کافی است).
2. `Θ(k)`. دنبالهٔ متناوب increment و decrement روی مرز `0111…1 ↔ 1000…0` هر بار k بیت را عوض می‌کند. تحلیل `O(1)` فقط برای افزایش تنها درست است.
</details>

## 📝 آزمون فصل ۱ (سؤال‌های واقعی کنکور ارشد کامپیوتر)
**زمان: ۲۵ دقیقه برای ۱۱ سؤال.** روی هیچ سؤالی بیشتر از ۴ دقیقه نمان.

**۱. (ارشد ۱۴۰۴، سؤال ۵۶)** فرض کنید `T(x) = 2T(x/2) + (8/9)·T(3x/4) + Θ(x²/log x)`. کدام مورد درست است؟
۱) `Θ(x² log x)` ۲) `Θ(x²/log x)` ۳) `Θ(x² log(log x))` ۴) `Θ(2 log x − log(log x))`

**۲. (ارشد ۱۴۰۳، سؤال ۶۱)** تابع بازگشتی زیر را در نظر بگیرید:
```c
int f(int n) {
    if (n == 0 || n == 1) return (n + 1);
    else if (n == 2) return 4;
    return (f(n-1) + 2*f(n-2) + f(n-3));
}
```
برای `n ≥ 3`، کدام گزینه بهترین کاندید برای `f(n)` است؟
۱) `f(n) ≤ 2ⁿ` ۲) `f(n) ≤ 3ⁿ` ۳) `f(n) ≤ 2ⁿ⁺¹` ۴) `f(n) ≤ 4ⁿ`

**۳. (ارشد ۱۴۰۳، سؤال ۶۳)** بهترین پیچیدگی زمانی مورد نیاز برای محاسبهٔ مجموع دو جملهٔ iام و jام از دنبالهٔ فیبوناچی چیست؟
۱) `O(i·j)` ۲) `O(max{i, j})` ۳) `O(2ⁱ + 2ʲ)` ۴) `O(max{2ⁱ, 2ʲ})`

**۴. (ارشد ۱۴۰۳، سؤال ۶۶)** فرض کنید `f(n) = n` و `g(n) = n^(1+sin n)` که n یک عدد صحیح مثبت است. کدام‌یک از گزاره‌های زیر درست است؟
I. `f(n) = O(g(n))` II. `f(n) = Ω(g(n))`
۱) فقط I ۲) فقط II ۳) نه I و نه II ۴) هم I و هم II

**۵. (ارشد ۱۴۰۲، سؤال ۵۷)** مرتبهٔ زمانی الگوریتم زیر کدام است؟
```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= n / i; j++)   // ⌊n/i⌋
        S.O;
```
۱) `O(n)` ۲) `O(n log n)` ۳) `O(n²)` ۴) `θ(n)`

**۶. (ارشد ۱۴۰۲، سؤال ۶۳)** یک الگوریتم یک آرایهٔ دوبعدی `n×n` را به‌عنوان ورودی دریافت می‌کند و زمان اجرای آن برحسب n عبارت است از `T(n) = O(n log n)`. زمان الگوریتم برحسب اندازهٔ ورودی `m = n²` کدام است؟
۱) `O(m² log m)` ۲) `O(m² log² m)` ۳) `O(√m log m)` ۴) `O(m log m)`

**۷. (ارشد ۱۴۰۲، سؤال ۶۴)** برای حل یک مسئله باید از بین چهار الگوریتم انتخاب کنید. کدام‌یک ارجحیت دارد؟
1. الگوریتم A نمونه‌ای به اندازهٔ n را با حل بازگشتی **بیست** نمونه با اندازهٔ `n/3` حل می‌کند و سپس راه‌حل‌ها را در زمان `O(n²)` ترکیب می‌کند.
2. الگوریتم B نمونه‌ای به اندازهٔ n را با حل بازگشتی **هشت** نمونه با اندازهٔ `n/2` حل می‌کند و سپس راه‌حل‌ها را در زمان `O(n³)` ترکیب می‌کند.
3. الگوریتم C نمونه‌ای به اندازهٔ n را با حل بازگشتی دو نمونه با اندازهٔ `2×n` حل می‌کند و سپس راه‌حل‌ها را در زمان `O(n)` ترکیب می‌کند.
4. الگوریتم D نمونه‌ای به اندازهٔ n را با حل بازگشتی دو نمونه با اندازهٔ `n−1` حل می‌کند و سپس راه‌حل‌ها را در زمان ثابت ترکیب می‌کند.

**۸. (ارشد ۱۴۰۲، سؤال ۶۷)** کدام‌یک از روابط بازگشتی زیر را **نمی‌توان** مستقیماً با قضیهٔ اصلی حل کرد؟
۱) `T(n) = 16T(n/4) + n` ۲) `T(n) = T(n/5) + 20` ۳) `T(n) = 3T(n/4) + n log n` ۴) `T(n) = 2T(n/2) + n log n`

**۹. (ارشد ۱۴۰۱، سؤال ۶۶)** در کدام مورد، توابع به‌ترتیب صعودی (و نه اکیداً صعودی) بر مبنای رشد تابع از سمت چپ به راست مرتب شده‌اند؟
1. `log n, log² n, log n², n log² n, log n!, log nⁿ`

## 🗂 کارت خلاصهٔ فصل ۱
- **نردبان:** `1 < log log n < log n < n^ε < n < n log n < nᵏ < 2ⁿ < n! < nⁿ`
- `log(n!) = Θ(n log n) = Θ(log nⁿ)`؛ `log n² = Θ(log n)` ولی `log² n` بزرگ‌تر است. توان نوسانی یعنی مقایسه‌ناپذیر.
- **حلقه:** حلقهٔ وابسته را جمع بزن. `i*=2` یعنی `log n`؛ `i=i*i` یعنی `log log n`؛ `j+=i` یعنی هارمونیک.
- **قضیهٔ اصلی:** `c = log_b a`. سه حالت کلاسیک «چندجمله‌ای» فاصله می‌خواهند. فاصلهٔ `log` در نسخهٔ کلاسیک «مستقیم حل نمی‌شود»؛ جوابش را با حالت گسترده بگیر (`k>−1`: `logᵏ⁺¹`؛ `k=−1`: `log log`؛ `k<−1`: `n^c`).
- **تقسیم نامساوی:** اگر `Σα<1` جواب `n` است؛ اگر `=1` جواب `n log n`؛ در غیر این صورت آکرا-بازی (`Σ aᵢbᵢᵖ = 1`).
- **`√n`:** قرار بده `n = 2ᵐ`. **`T(n/log n)`:** جواب `log n / log log n`.
- **سرشکن:** دو برابر کردن `O(1)`، اضافهٔ ثابت `Θ(n)`، شمارندهٔ دوطرفه `Θ(k)`.
