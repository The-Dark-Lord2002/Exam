# فصل ۴: روابط بازگشتی و توابع مولد

> **سهم در کنکور:** ۶ سؤال در ارشد ۱۳۹۸ تا ۱۴۰۴ (۳ رابطهٔ بازگشتی و ۳ تابع مولد). تیپ‌ها: «کدام رابطه این مسئلهٔ شمارشی را توصیف می‌کند؟»، حل یک رابطهٔ ناهمگن، و «تعداد افرازها ضریب x^n در کدام عبارت است؟».
> **زمان مطالعه:** یک بلوک ۹۰ دقیقه‌ای.

---

## درس ۱: ساختن رابطهٔ بازگشتی برای یک مسئلهٔ شمارشی

**روش:** روی **آخرین** (یا اولین) قدم حالت‌بندی کن. هر حالت، مسئلهٔ کوچک‌تری از همان نوع است.

| مسئله | رابطه |
|---|---|
| رشته‌های دودویی به طول n بدون دو ۱ متوالی | `aₙ = aₙ₋₁ + aₙ₋₂` (فیبوناچی) |
| کاشی‌کاری `2×n` با دومینو | `aₙ = aₙ₋₁ + aₙ₋₂` |
| رشته‌های به طول n در مبنای b با تعداد **زوج** از یک رقم خاص | `aₙ = (b−2)·aₙ₋₁ + bⁿ⁻¹` |
| پریش‌ها | `Dₙ = (n−1)(Dₙ₋₁ + Dₙ₋₂)` |
| هانوی | `aₙ = 2aₙ₋₁ + 1` |

**ریشهٔ رابطهٔ «تعداد زوج»:** به رشتهٔ خوب به طول `n−1` یکی از `b−1` رقم دیگر را اضافه کن، یا به رشتهٔ **بد** (که `bⁿ⁻¹ − aₙ₋₁` تا هستند) همان رقم خاص را اضافه کن:
`aₙ = (b−1)aₙ₋₁ + (bⁿ⁻¹ − aₙ₋₁) = (b−2)aₙ₋₁ + bⁿ⁻¹`
فرم بسته: `aₙ = (bⁿ + (b−2)ⁿ)/2`.

**ریشهٔ رابطهٔ پریش:** عدد ۱ به جای k می‌رود (`n−1` انتخاب). اگر k هم به جای ۱ برود، بقیه `Dₙ₋₂` حالت دارند؛ وگرنه `Dₙ₋₁`.

---

## درس ۲: حل رابطهٔ خطی همگن

برای `aₙ = c₁aₙ₋₁ + c₂aₙ₋₂`، معادلهٔ مشخصه `r² = c₁r + c₂` را حل کن:
- دو ریشهٔ متمایز r₁ و r₂: `aₙ = A·r₁ⁿ + B·r₂ⁿ`
- ریشهٔ مضاعف r: `aₙ = (A + B·n)·rⁿ`

ثابت‌های A و B را از شرایط اولیه پیدا کن.

**مثال:** `aₙ = 5aₙ₋₁ − 6aₙ₋₂` با `a₀ = 1` و `a₁ = 4`.
- ریشه‌ها ۲ و ۳ هستند، پس `aₙ = A·2ⁿ + B·3ⁿ`.
- از `A + B = 1` و `2A + 3B = 4` نتیجه می‌شود `B = 2` و `A = −1`.
- جواب: `aₙ = 2·3ⁿ − 2ⁿ`. (چک: `a₂ = 5·4 − 6·1 = 14 = 18 − 4` ✓)

---

## درس ۳: رابطهٔ ناهمگن، با ترفند تقسیم

- `aₙ = aₙ₋₁ + f(n)` ⇐ `aₙ = a₀ + Σ f(k)`.
- `aₙ = 2aₙ₋₁ + 1` با `a₀ = 0` ⇐ `aₙ = 2ⁿ − 1`.
- **ضریب متغیر:** `aₙ = n·aₙ₋₁ + g(n)` را بر `n!` تقسیم کن. با `bₙ = aₙ/n!` رابطه می‌شود `bₙ = bₙ₋₁ + g(n)/n!`.
- **میان‌بُر تستی:** گزینه‌ها را در `n = 1, 2, 3` امتحان کن. معمولاً دو مقدار کافی است.

### تمرین درس ۱ تا ۳
1. تعداد رشته‌های دودویی به طول ۵ بدون دو ۱ متوالی؟ (`a₁ = 2`، `a₂ = 3`)
2. `aₙ = 4aₙ₋₁ − 4aₙ₋₂` با `a₀ = 1` و `a₁ = 4` را حل کن.

<details>
<summary>جواب‌ها</summary>

1. `5, 8, 13` پس `a₅ = 13`.
2. ریشهٔ مضاعف ۲: `aₙ = (A + Bn)·2ⁿ`. از `A = 1` و `2(1 + B) = 4` داریم `B = 1`. جواب: `aₙ = (n+1)·2ⁿ` (چک: `a₂ = 16 − 4 = 12 = 3·4` ✓).
</details>

## درس ۴: توابع مولد

تابع مولد دنبالهٔ `aₙ` برابر `A(x) = Σ aₙxⁿ` است.

| تابع | دنباله |
|---|---|
| `1/(1−x)` | `1, 1, 1, …` |
| `1/(1−x)ᵏ` | `C(n+k−1, k−1)` (ترکیب با تکرار) |
| `x·A′(x)` | `n·aₙ` |
| `A(x)/(1−x)` | مجموع جزئی `a₀ + … + aₙ` |
| `1/(1−xᵏ) = 1 + xᵏ + x²ᵏ + …` | استفاده از قطعهٔ k به هر تعداد |
| `(1 + xᵏ)` | استفاده از قطعهٔ k حداکثر یک بار |

### افراز و پرداخت سکه (ترتیب مهم نیست)
تعداد راه‌های نوشتن n با قطعه‌های `{1, 2, 5}` (هر کدام به هر تعداد) **ضریب `xⁿ`** در این عبارت است:
`1/((1−x)(1−x²)(1−x⁵)) = (1 + x + x² + …)(1 + x² + x⁴ + …)(1 + x⁵ + x¹⁰ + …)`

⚠️ گزینه‌هایی مثل `(x + x² + x⁵)ⁿ` یا `1/(1 − (x + x² + x⁵))` **ترتیب‌دار** می‌شمارند (ترکیب، نه افراز). مراقب این تله باش.

### تمرین درس ۴
1. تابع مولد تعداد راه‌های پرداخت n تومان با سکه‌های ۱ و ۳ تومانی (ترتیب نامهم)؟
2. ضریب `x⁵` در `1/(1−x)³`؟

<details>
<summary>جواب‌ها</summary>

1. `1/((1−x)(1−x³))`
2. `C(5+2, 2) = 21`
</details>

## 📝 آزمون فصل ۴ (سؤال‌های واقعی کنکور ارشد کامپیوتر)
**زمان: ۱۵ دقیقه.**

**۱. (ارشد ۱۴۰۴، سؤال ۴۵)** جواب رابطهٔ بازگشتی `aₙ = n·aₙ₋₁ + n!` با `a₁ = 1` کدام است؟
۱) `n(n!)` ۲) `n` ۳) `n² − 1 + 2ⁿ⁻¹` ۴) `n!·2ⁿ⁻¹`

**۲. (ارشد ۱۴۰۱، سؤال ۴۷)** جایگشتی از اعداد ۱ تا n که در آن هیچ عدد i در محل iام قرار نگرفته باشد، یک پریش نامیده می‌شود. فرض کنید `Dₙ` برابر تعداد پریش‌های مختلف اعداد ۱ تا n باشد. کدام رابطهٔ بازگشتی برای `Dₙ` به ازای `n > 2` برقرار است؟
1. `Dₙ = (n−1)Dₙ₋₁ + (n−2)Dₙ₋₂`
2. `Dₙ = (n−1)(Dₙ₋₁ + Dₙ₋₂)`
3. `Dₙ = n·Dₙ₋₁ − (n−1)Dₙ₋₂`
4. `Dₙ = (n−1)Dₙ₋₁`

**۳. (ارشد ۱۴۰۰، سؤال ۵۰)** فرض کنید `aₙ` برابر با تعداد اعداد حداکثر n رقمی در مبنای ۵ باشد که تعداد رقم‌های یک آن زوج است. در این صورت `aₙ` در کدام‌یک از رابطه‌های بازگشتی زیر صدق می‌کند؟
۱) `aₙ = 3aₙ₋₁ + 5ⁿ⁻¹` ۲) `aₙ = 3aₙ₋₁ + aₙ₋₂` ۳) `aₙ = 4aₙ₋₁ + aₙ₋₂` ۴) `aₙ = 4aₙ₋₁ + 5ⁿ⁻¹`

**۴. (ارشد ۱۴۰۴، سؤال ۴۴)** اگر `f(x)` تابع مولد معمولی دنبالهٔ `{n!}` باشد، تابع مولد معمولی دنبالهٔ `{n(n!)}` کدام است؟
۱) `x∫f(x)` ۲) `x·f(x)` ۳) `f(x)/x` ۴) `x·f′(x)`

**۵. (ارشد ۱۴۰۰، سؤال ۴۷)** تعداد راه‌های افراز نامرتب عدد ۵۶ به اعداد ۱ و ۲ و ۵ برابر با ضریب `x⁵⁶` در کدام‌یک از عبارات زیر است؟
1. `1 / (1 − (x + x² + x⁵))`
2. `1 / ((1−x)(1−x²)(1−x⁵))`
3. `(1 + x + x² + x⁵)⁵⁶`
4. `[(1+x)(1+x²)(1+x⁵)]⁵⁶`

**۶. (ارشد ۱۳۹۹، سؤال ۵۰)** تعداد راه‌های پرداختن ۶۳ ریال به کمک سکه‌های ۱ و ۲ و ۵ ریالی، بدون آنکه ترتیب پرداخت سکه‌ها مهم باشد، برابر با ضریب `x⁶³` در کدام عبارت است؟
1. `(x + x² + x⁵)⁶³`
2. `(1 + x + x² + x⁵)⁶³`
3. `((1+x)(1+x²)(1+x⁵))⁶³`
4. `(1 + x + x² + …)(1 + x² + x⁴ + …)(1 + x⁵ + x¹⁰ + …)`

<details>
<summary>جواب‌ها و راه‌حل (کلید رسمی سازمان سنجش)</summary>

| سؤال | ۱ | ۲ | ۳ | ۴ | ۵ | ۶ |
|---|---|---|---|---|---|---|
| کلید | ۱ | ۲ | ۱ | ۴ | ۲ | ۴ |

**۱. گزینهٔ ۱.** بر `n!` تقسیم کن: `bₙ = aₙ/n!` در `bₙ = bₙ₋₁ + 1` با `b₁ = 1` صدق می‌کند، پس `bₙ = n` و `aₙ = n·n!`. (چک: `a₂ = 2·1 + 2 = 4 = 2·2!` ✓)

**۲. گزینهٔ ۲.** رابطهٔ پریش (درس ۱). چک: `D₄ = 3(D₃ + D₂) = 3(2 + 1) = 9` ✓.

**۳. گزینهٔ ۱.** فرمول درس ۱ با `b = 5`: `aₙ = 3aₙ₋₁ + 5ⁿ⁻¹`. («حداکثر n رقمی» یعنی رشتهٔ n رقمی با صفرهای ابتدایی.) چک: `a₁ = 4` و `a₂ = 3·4 + 5 = 17 = (25 + 9)/2` ✓.

**۴. گزینهٔ ۴.** `x·f′(x) = Σ n·n!·xⁿ`.

**۵. گزینهٔ ۲.** افراز با قطعه‌های ۱، ۲ و ۵ (هر کدام به هر تعداد). گزینهٔ ۱ ترتیب‌دار می‌شمارد.

**۶. گزینهٔ ۴.** همان عبارت سؤال قبل، به شکل سری‌های بازشده.
</details>

## 🗂 کارت خلاصهٔ فصل ۴
- رابطه بساز: روی قدم آخر حالت‌بندی کن. «تعداد زوجِ یک رقم در مبنای b»: `aₙ = (b−2)aₙ₋₁ + bⁿ⁻¹`. پریش: `(n−1)(Dₙ₋₁ + Dₙ₋₂)`.
- همگن: معادلهٔ مشخصه. ریشهٔ مضاعف r یعنی `(A + Bn)rⁿ`.
- `aₙ = n·aₙ₋₁ + …` را بر `n!` تقسیم کن. گزینه‌ها را با n کوچک چک کن.
- `1/(1−xᵏ)` یعنی قطعهٔ k به هر تعداد؛ `(1 + xᵏ)` یعنی حداکثر یک بار. `x·A′` یعنی `n·aₙ`. ضرب در `1/(1−x)` یعنی مجموع جزئی.
