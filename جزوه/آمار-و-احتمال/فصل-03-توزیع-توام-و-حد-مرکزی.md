# فصل ۳: توزیع توأم، کوواریانس، و قضیهٔ حد مرکزی

> **سهم در کنکور:** ۶ سؤال در ارشد ۱۳۹۸ تا ۱۴۰۴ (۴ توزیع توأم، ۱ کوواریانس، ۱ حد مرکزی). سؤال‌های جدول توأم یک‌دقیقه‌ای‌اند.
> **زمان مطالعه:** یک بلوک ۹۰ دقیقه‌ای.

---

## درس ۱: جدول توأم، حاشیه‌ای و شرطی

- **حاشیه‌ای:** `P(X = x) = Σ_y P(X = x, Y = y)` (جمع سطر یا ستون).
- **شرطی:** `P(X = x | Y = y) = P(x, y)/P(Y = y)`، یعنی خانه تقسیم بر جمع همان سطر یا ستون.
- **مجهول در جدول:** از شرط داده‌شده یک معادله، و از «جمع همهٔ خانه‌ها = ۱» معادلهٔ دیگر را بنویس.
- **استقلال:** برای **همهٔ** خانه‌ها `P(x, y) = P(x)·P(y)`.

### پیوسته
- `P((X, Y) ∈ A) = ∬_A f(x, y)`.
- **دو نمایی مستقل با نرخ ۱:** `P(X < aY) = a/(1 + a)`. مثلاً `P(X < Y) = 1/2` و `P(X < 2Y) = 2/3`.
- **شرط تودرتو:** اگر `A ⊂ B` آنگاه `P(A | B) = P(A)/P(B)`.

---

## درس ۲: کوواریانس و همبستگی

- `Cov(X, Y) = E[XY] − E[X]·E[Y]`. مستقل بودن ⇐ `Cov = 0`، ولی برعکسش لزوماً نه.
- **دوخطی است:** `Cov(X, Y + Z) = Cov(X, Y) + Cov(X, Z)` و `Cov(X, X) = Var(X)`.
- `Var(X ± Y) = Var(X) + Var(Y) ± 2Cov(X, Y)`.
- `ρ = Cov/(σ_X·σ_Y)` و همیشه `−1 ≤ ρ ≤ 1`.
- **تیپ «شمارش‌های هم‌پوشان»:** اگر `X = X₁` و `Z = X₁ + X₂` (با پرتاب‌های مستقل)، آنگاه `Cov(X, Z) = Var(X₁)`. شمارش‌هایی که پرتاب مشترک ندارند، کوواریانس صفر دارند.

## درس ۳: قضیهٔ حد مرکزی و چبیشف

- جمع n متغیر مستقل هم‌توزیع تقریباً **نرمال** با میانگین `nμ` و واریانس `nσ²` است.
- **بدون محاسبه:** `P(S > nμ) ≈ 1/2`، چون نرمال حول میانگینش متقارن است.
- **چبیشف:** `P(|X − μ| ≥ kσ) ≤ 1/k²`.

### تمرین فصل ۳
1. جدول: `P(0,0) = 0.1`، `P(0,1) = 0.3`، `P(1,0) = 0.2`، `P(1,1) = 0.4`. `P(Y = 1 | X = 1)`؟ آیا X و Y مستقل‌اند؟
2. X و Y مستقل با واریانس‌های ۴ و ۹. `Var(2X − Y)`؟
3. جمع ۱۰۰ متغیر مستقل `U(0,1)`: میانگین و واریانس تقریبی؟

## 🗂 کارت خلاصهٔ فصل ۳
- شرطی در جدول: خانه تقسیم بر جمع سطر یا ستونش. مجهول‌ها از شرط داده‌شده + «جمع = ۱».
- نمایی‌های نرخ ۱: `P(X < aY) = a/(1+a)`. اگر `A ⊂ B`: `P(A|B) = P(A)/P(B)`.
- `Cov` دوخطی است؛ شمارش‌های هم‌پوشان: `Cov = Var` بخش مشترک.
- حد مرکزی: `P(S > nμ) ≈ 1/2`. چبیشف: `≤ 1/k²`.
