## درس ۱: جدول توأم، حاشیه‌ای و شرطی

- **حاشیه‌ای:** `P(X = x) = Σ_y P(X = x, Y = y)` (جمع سطر یا ستون).
- **شرطی:** `P(X = x | Y = y) = P(x, y)/P(Y = y)`، یعنی خانه تقسیم بر جمع همان سطر یا ستون.
- **مجهول در جدول:** از شرط داده‌شده یک معادله، و از «جمع همهٔ خانه‌ها = ۱» معادلهٔ دیگر را بنویس.
- **استقلال:** برای **همهٔ** خانه‌ها `P(x, y) = P(x)·P(y)`.

**مثال:**

| | `Y = 0` | `Y = 1` | جمع سطر |
|---|---|---|---|
| `X = 0` | `0.2` | `0.1` | `0.3` |
| `X = 1` | `0.3` | `0.4` | `0.7` |
| جمع ستون | `0.5` | `0.5` | `1` |

- **حاشیه‌ای:** `P(X = 1) = 0.3 + 0.4 = 0.7` و `P(Y = 1) = 0.1 + 0.4 = 0.5`.
- **شرطی:** `P(Y = 1 | X = 0) = 0.1/0.3 = 1/3`.
- **استقلال:** `P(X=0)·P(Y=0) = 0.3 × 0.5 = 0.15 ≠ 0.2` ⇐ مستقل **نیستند** (یک خانهٔ ناجور کافی است).
- **مجهول:** اگر به‌جای ۰٫۲ و ۰٫۴ مجهول‌های a و b بودند و `P(Y = 1 | X = 1) = 0.5` داده شده بود: `b/(0.3 + b) = 0.5` ⇐ `b = 0.3`؛ و از جمع کل: `a = 1 − 0.1 − 0.3 − 0.3 = 0.3`.

### پیوسته
- `P((X, Y) ∈ A) = ∬_A f(x, y)`.
- **دو نمایی مستقل با نرخ ۱:** `P(X < aY) = a/(1 + a)`. مثلاً `P(X < Y) = 1/2` و `P(X < 2Y) = 2/3`.
- **شرط تودرتو:** اگر `A ⊂ B` آنگاه `P(A | B) = P(A)/P(B)`.

**مثال:**
- **انتگرال دوگانه:** با `f = 1` روی مربع واحد، `P(X + Y < 1)` مساحت مثلث زیر خط `x + y = 1` است: `1/2`.
- **دو نمایی:** `P(X < 2Y) = ∫₀^∞ (1 − e^(−2y))·e^(−y) dy = 1 − 1/3 = 2/3` ✓.
- **تودرتو:** A = «تاس ۶ آمد» و B = «تاس زوج آمد». `A ⊂ B`، پس `P(A | B) = (1/6)/(1/2) = 1/3`.

## درس ۲: کوواریانس و همبستگی

- `Cov(X, Y) = E[XY] − E[X]·E[Y]`. مستقل بودن ⇐ `Cov = 0`، ولی برعکسش لزوماً نه.
- **دوخطی است:** `Cov(X, Y + Z) = Cov(X, Y) + Cov(X, Z)` و `Cov(X, X) = Var(X)`.
- `Var(X ± Y) = Var(X) + Var(Y) ± 2Cov(X, Y)`.
- `ρ = Cov/(σ_X·σ_Y)` و همیشه `−1 ≤ ρ ≤ 1`.
- **تیپ «شمارش‌های هم‌پوشان»:** اگر `X = X₁` و `Z = X₁ + X₂` (با پرتاب‌های مستقل)، آنگاه `Cov(X, Z) = Var(X₁)`. شمارش‌هایی که پرتاب مشترک ندارند، کوواریانس صفر دارند.

**مثال برای هر قاعده:**
- **ناهمبسته ولی وابسته:** X یکنواخت روی `{−1, 0, 1}` و `Y = X²`. `Cov = E[X³] − E[X]·E[X²] = 0 − 0 = 0`، ولی Y کاملاً از X تعیین می‌شود.
- **واریانس جمع و ρ:** با `Var(X) = 4`، `Var(Y) = 9` و `Cov = 3`: `Var(X + Y) = 4 + 9 + 6 = 19` و `ρ = 3/(2 × 3) = 0.5`.
- **هم‌پوشان:** دو پرتاب سکه با `X₁, X₂` (۱ اگر شیر). `X = X₁` و `Z = X₁ + X₂` ⇐ `Cov(X, Z) = Var(X₁) = 1/4`. ولی `Cov(X₁, X₂) = 0`.

## درس ۳: قضیهٔ حد مرکزی و چبیشف

- جمع n متغیر مستقل هم‌توزیع تقریباً **نرمال** با میانگین `nμ` و واریانس `nσ²` است.
- **بدون محاسبه:** `P(S > nμ) ≈ 1/2`، چون نرمال حول میانگینش متقارن است.
- **چبیشف:** `P(|X − μ| ≥ kσ) ≤ 1/k²`.

**مثال:** جمع ۱۰۰ تاس: میانگین `100 × 3.5 = 350` و واریانس `100 × 35/12 ≈ 292` (انحراف معیار ≈ ۱۷).
- `P(S > 350) ≈ 1/2`.
- `P(S > 384) ≈ P(Z > 34/17) = P(Z > 2) ≈ 0.023`.
- **چبیشف با `k = 2`:** حداکثر `1/4` از مقادیر بیش از ۲ انحراف معیار از میانگین فاصله دارند. برای نرمال، مقدار واقعی حدود `0.05` است؛ چبیشف برای هر توزیعی درست است، پس محافظه‌کار است.

3. جمع ۱۰۰ متغیر مستقل `U(0,1)`: میانگین و واریانس تقریبی؟

## 🗂 کارت خلاصهٔ فصل ۳
- شرطی در جدول: خانه تقسیم بر جمع سطر یا ستونش. مجهول‌ها از شرط داده‌شده + «جمع = ۱».
- نمایی‌های نرخ ۱: `P(X < aY) = a/(1+a)`. اگر `A ⊂ B`: `P(A|B) = P(A)/P(B)`.
- `Cov` دوخطی است؛ شمارش‌های هم‌پوشان: `Cov = Var` بخش مشترک.
- حد مرکزی: `P(S > nμ) ≈ 1/2`. چبیشف: `≤ 1/k²`.
