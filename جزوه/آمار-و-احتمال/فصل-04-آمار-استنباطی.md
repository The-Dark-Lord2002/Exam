## درس ۱: برآورد

| مفهوم | تعریف یا روش |
|---|---|
| **نااریب** | `E[θ̂] = θ` |
| **گشتاوری (MME)** | `E[X]` (بر حسب θ) را برابر `x̄` بگذار و θ را حل کن |
| **درست‌نمایی بیشینه (MLE)** | `Σ ln f(xᵢ; θ)` را بیشینه کن |

**مثال برای هر سطر جدول:**
- **نااریب:** `x̄` برای μ نااریب است. ولی در `U(0, θ)`، بیشینهٔ نمونهٔ ۳تایی میانگین `3θ/4` دارد؛ یعنی اریب است و θ را کم برآورد می‌کند.
- **گشتاوری:** نمونهٔ پواسون `1, 3, 2, 2` ⇐ `x̄ = 2` و چون `E[X] = λ`، `λ̂ = 2`.
- **MLE:** در ۱۰ پرتاب، ۷ شیر. `ln L = 7 ln p + 3 ln(1−p)`؛ مشتق `7/p − 3/(1−p) = 0` ⇐ `p̂ = 0.7`.

**مثال‌های آماده:**
- `f = (θ+1)·x^θ` روی `(0,1)`: `E[X] = (θ+1)/(θ+2)`.
- `Beta(θ, 1)` با `f = θ·x^(θ−1)`: `E[X] = θ/(θ+1)`، پس `1 − E[X] = 1/(θ+1)`. در نتیجه **برآورد نااریب `2/(1+θ)` برابر `2(1 − x̄)` است**.
- نمایی با میانگین θ: هم گشتاوری هم MLE برابر `x̄`.
- `U(0, θ)`: گشتاوری `2x̄` است و MLE بیشینهٔ نمونه.

**مثال:**
- برای `f = (θ+1)·x^θ` با `x̄ = 0.75`: `(θ+1)/(θ+2) = 0.75` ⇐ `θ̂ = 2`.
- برای `U(0, θ)` با نمونهٔ `1, 2, 9`: گشتاوری `2 × 4 = 8` است، کمتر از دادهٔ ۹ که دیده‌ایم (ناممکن!). MLE برابر **۹** است.

## درس ۲: فاصلهٔ اطمینان

- σ معلوم: `x̄ ± z_(α/2)·σ/√n`. برای ۹۵٪، `z = 1.96` (در بعضی تست‌ها گرد شده به ۲). برای ۹۰٪، `z = 1.64`.
- **حجم نمونه برای حاشیهٔ خطای E:** `n = (z·σ/E)²` (رو به بالا گرد کن).
- σ نامعلوم: به جای z از `t_(n−1)` و به جای σ از s استفاده کن.
- `P(|X̄ − μ| < c) = 0.9` ⇐ `c = 1.64·σ/√n`.

**مثال برای هر مورد:**
- **σ معلوم، ۹۰٪:** `σ = 10`، `n = 100`، `x̄ = 70` ⇐ `70 ± 1.64 × 1 = (68.36, 71.64)`.
- **حجم نمونه:** `E = 0.5`، `σ = 2`، اطمینان ۹۰٪ ⇐ `(1.64 × 2/0.5)² ≈ 43.03` ⇐ **۴۴**.
- **σ نامعلوم:** `n = 9`، `x̄ = 20`، `s = 3` و `t₈ = 2.306` ⇐ `20 ± 2.306 × 3/3 = (17.69, 22.31)`.
- **c:** با `σ = 4` و `n = 16`: `c = 1.64 × 4/4 = 1.64`.

## درس ۳: آزمون فرض

| مفهوم | تعریف |
|---|---|
| خطای نوع اول (α) | `P(رد H₀ | H₀ درست است)` |
| توان | `P(رد H₀ | H₁ درست است) = 1 − β` |
| p-value | احتمال دیدن آماره‌ای به این شدت (یا شدیدتر) **با فرض H₀** |
| تصمیم | اگر `p-value < α`، `H₀` را رد کن |

**مثال (تشبیه):** H₀ = «آتش‌سوزی نیست». خطای نوع اول یعنی آژیر بی‌دلیل به صدا درآید. توان یعنی وقتی واقعاً آتش هست، آژیر بزند.

- آمارهٔ z: `(x̄ − μ₀)/(σ/√n)`. در آزمون **دوطرفه**، `p-value = 2(1 − Φ(|z|))`.
- **آزمون زوجی (قبل و بعد):** `d̄/(s_d/√n)` که `s_d² = s_x² + s_y² − 2s_xy`.
- **آزمون با یک مشاهده و ناحیهٔ رد داده‌شده:** α و توان را مستقیم با انتگرال چگالی روی ناحیهٔ رد حساب کن.

**مثال برای هر مورد:**
- **z دوطرفه:** `H₀: μ = 50`، `σ = 10`، `n = 25`، `x̄ = 54` ⇐ `z = 4/2 = 2` و `p-value = 2(1 − 0.977) ≈ 0.046 < 0.05` ⇐ H₀ رد می‌شود.
- **زوجی:** اختلاف‌های «بعد − قبل» برای ۳ نفر `1, 3, 2` ⇐ `d̄ = 2`، `s_d = 1` و آماره `2/(1/√3) ≈ 3.46`.
- **یک مشاهده:** X نمایی، `H₀`: میانگین ۱ و `H₁`: میانگین ۲. اگر `X > 3` باشد H₀ را رد کن. `α = P(X > 3 | میانگین ۱) = e⁻³ ≈ 0.05` و توان `= P(X > 3 | میانگین ۲) = e^(−1.5) ≈ 0.22`.

## درس ۴: تحلیل واریانس و رگرسیون

- **ANOVA یک‌طرفه:** میانگین کل `x̄ = Σ nᵢx̄ᵢ / Σ nᵢ`؛ خطا `SSE = Σ (nᵢ − 1)·sᵢ²`؛ تیمار `SSTr = Σ nᵢ(x̄ᵢ − x̄)²`.
- **رگرسیون:** ضریب `bⱼ` یعنی «یک واحد افزایش `xⱼ`، با ثابت بودن بقیه، y را `bⱼ` تغییر می‌دهد». **به واحد متغیر دقت کن** (مثلاً «هزار خط»).

**مثال:**
- **ANOVA:** دو گروه ۳تایی با `x̄₁ = 10, s₁² = 4` و `x̄₂ = 14, s₂² = 2`. میانگین کل ۱۲؛ `SSE = 2 × 4 + 2 × 2 = 12`؛ `SSTr = 3(10 − 12)² + 3(14 − 12)² = 24`.
- **رگرسیون:** `y = 5 + 2.5x₁ − 0.8x₂` که x₁ بر حسب «هزار خط» است. ۵۰۰ خط بیشتر (یعنی `x₁ += 0.5`)، با ثابت بودن x₂، y را `1.25` زیاد می‌کند.

### تمرین فصل ۴
1. `σ = 10`، `n = 25`، `x̄ = 50`. فاصلهٔ اطمینان ۹۵٪؟
2. حاشیهٔ خطای ۲ با `σ = 10` و اطمینان ۹۵٪: n حداقل چقدر است؟
3. برآورد گشتاوری θ برای `U(0, θ)` با نمونهٔ `2, 4, 6`؟

## 🗂 کارت خلاصهٔ فصل ۴
- گشتاوری: `E[X](θ) = x̄`. `Beta(θ,1)`: نااریب `2/(1+θ)` برابر `2(1 − x̄)`.
- فاصلهٔ اطمینان: `x̄ ± zσ/√n`؛ `n = (zσ/E)²`؛ ۹۰٪ ⇐ `1.64`، ۹۵٪ ⇐ `1.96`.
- α = رد با فرض H₀؛ توان = رد با فرض H₁. p-value دوطرفه: `2(1 − Φ(|z|))`. زوجی: `s_d² = s_x² + s_y² − 2s_xy`.
- `SSE = Σ(nᵢ − 1)sᵢ²`. ضریب رگرسیون را با واحدش بخوان.
