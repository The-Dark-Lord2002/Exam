> **سهم در کنکور:** ۱۳ سؤال در ارشد ۱۳۹۸ تا ۱۴۰۴، پرتکرارترین فصل این درس. تیپ‌ها: بی‌حافظگی، رقابت نمایی‌ها یا پواسون‌ها، امید با چگالی داده‌شده، و تبدیل متغیر.
> **زمان مطالعه:** دو بلوک ۹۰ دقیقه‌ای.

## درس ۱: امید و واریانس

- `E[aX + b] = a·E[X] + b` و `Var(aX + b) = a²·Var(X)`. همچنین `Var(X) = E[X²] − E[X]²`.
- `E[g(X)] = ∫ g(x)·f(x) dx` (یا `Σ`). **لازم نیست** اول توزیع `g(X)` را پیدا کنی.
- **امید ممکن است وجود نداشته باشد:** مثلاً `P(X = x) = k/x²`، چون `Σ x·k/x² = k·Σ 1/x = ∞`.
- **گشتاورها توزیع را مشخص می‌کنند:** اگر `E[Xʳ] = 1/(r+1)`، X همان یکنواخت `(0,1)` است.
- **سری درون امید:** `E[1 + X + X² + …] = E[1/(1−X)]`.

**مثال برای هر قاعده:**
- **خطی بودن:** X عدد یک تاس سالم: `E[X] = 3.5`، `E[X²] = 91/6`، پس `Var(X) = 91/6 − 3.5² = 35/12`. برای `Y = 2X + 1`: `E[Y] = 8` و `Var(Y) = 4 × 35/12 = 35/3`.
- **`E[g(X)]` مستقیم:** با `X ~ U(0, 1)`: `E[X²] = ∫₀¹ x² dx = 1/3`؛ لازم نیست توزیع `X²` را پیدا کنی.
- **امید ناموجود:** با `k = 6/π²`، جمع `Σ k/x²` برابر ۱ است (توزیع معتبر)، ولی `Σ x·k/x² = k·(1 + 1/2 + 1/3 + …) = ∞`.
- **گشتاورها:** برای `U(0, 1)`: `E[Xʳ] = ∫₀¹ xʳ dx = 1/(r+1)` ✓.
- **سری:** با `X ~ U(0, 1/2)`: `E[1/(1−X)] = 2∫₀^½ dx/(1−x) = 2 ln 2 ≈ 1.39`.

## درس ۲: توزیع‌های گسسته

| توزیع | `P(X = k)` | امید | واریانس | نکته |
|---|---|---|---|---|
| دوجمله‌ای `(n, p)` | `C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ` | `np` | `np(1−p)` | |
| هندسی (تعداد آزمایش تا اولین موفقیت) | `p(1−p)ᵏ⁻¹` | `1/p` | `(1−p)/p²` | **بی‌حافظه** |
| پواسون `λ` | `e^(−λ)·λᵏ/k!` | `λ` | `λ` | جمع پواسون‌های مستقل، پواسون است |
| فوق‌هندسی | `C(K,k)·C(N−K, n−k)/C(N, n)` | `nK/N` | | انتخاب **بدون جایگذاری**؛ اگر N بزرگ باشد، تقریباً دوجمله‌ای |

- **رقابت پواسون‌ها:** اگر رخدادهای مستقل با نرخ‌های `λᵢ` داشته باشیم، احتمال اینکه اولین رخداد از نوع i باشد `λᵢ/Σλ` است.
- **دو هندسی مستقل هم‌توزیع:** `P(X = Y) = Σ p²(1−p)²⁽ᵏ⁻¹⁾ = p/(2−p)`.

**مثال برای هر سطر جدول:**
- **دوجمله‌ای:** ۳ بار پرتاب سکه، احتمال دقیقاً ۲ شیر: `C(3,2)/8 = 3/8`؛ امید `3 × ½ = 1.5`.
- **هندسی:** تاس را تا آمدن ۶ بینداز. احتمال اینکه اولین ۶ در پرتاب سوم بیاید: `(5/6)²·(1/6) = 25/216`؛ امید `1/p = 6` پرتاب. **بی‌حافظه:** اگر ۴ پرتاب اول ۶ نیامده، امید پرتاب‌های باقی‌مانده باز هم ۶ است.
- **پواسون:** به‌طور میانگین ۲ تماس در ساعت: `P(0) = e⁻² ≈ 0.135` و `P(2) = e⁻²·2²/2! ≈ 0.271`. جمع دو پواسون مستقل با `λ = 2` و `λ = 3`، پواسون با `λ = 5` است.
- **فوق‌هندسی:** از ۱۰ لامپ که ۳ تا خراب‌اند، ۲ تا برمی‌داریم. احتمال دقیقاً یک خراب: `C(3,1)·C(7,1)/C(10,2) = 21/45 = 7/15`؛ امید `2 × 3/10 = 0.6`.
- **رقابت:** تماس‌ها با نرخ ۲ و ایمیل‌ها با نرخ ۳ در ساعت. احتمال اینکه اولین رخداد تماس باشد: `2/5`.
- **`P(X = Y)`:** با `p = ½`: `(1/2)/(3/2) = 1/3`.

## درس ۳: توزیع‌های پیوسته

| توزیع | چگالی | امید | واریانس | نکته |
|---|---|---|---|---|
| یکنواخت `(a, b)` | `1/(b−a)` | `(a+b)/2` | `(b−a)²/12` | **شرطی‌اش هم یکنواخت است** |
| نمایی (میانگین θ) | `(1/θ)·e^(−x/θ)` | `θ` | `θ²` | بی‌حافظه: `P(X > a+b | X > b) = P(X > a)` |
| نرمال | | `μ` | `σ²` | |
| بتا `(a, b)` | `x^(a−1)·(1−x)^(b−1)/B(a,b)` | `a/(a+b)` | | `Beta(θ, 1)` چگالی `θ·x^(θ−1)` دارد |

**مثال برای هر سطر جدول:**
- **یکنواخت `(0, 10)`:** امید ۵ و واریانس `100/12 ≈ 8.33`. اگر بدانیم `X > 5`، X روی `(5, 10)` یکنواخت است.
- **نمایی با میانگین ۵:** `P(X > 5) = e⁻¹ ≈ 0.37`.
- **نرمال** با `μ = 100` و `σ = 15`: `P(X > 130) = P(Z > 2) ≈ 0.023`. قاعدهٔ سرانگشتی: حدود ۶۸٪، ۹۵٪ و ۹۹٫۷٪ داده‌ها در فاصلهٔ ۱، ۲ و ۳ انحراف معیار از میانگین‌اند.
- **بتا `(2, 1)`:** چگالی `2x` روی `(0, 1)` و امید `∫ x·2x dx = 2/3 = a/(a+b)` ✓.

### ترفندهای نمایی
- **بی‌حافظه:** اگر `P(X > 1) = 0.5` آنگاه `P(X ≥ b) = (1/2)ᵇ`.
- **کمینهٔ نمایی‌های مستقل:** نمایی با نرخ `Σ λᵢ`.
- **بیشینهٔ دو نمایی مستقل هم‌توزیع با میانگین θ:** `θ + θ/2` (اول یکی تمام می‌شود، بعد بی‌حافظگی).
- **آمیزهٔ نمایی‌ها:** اگر `F(t) = 1 − a·e^(−λt) − (1−a)·e^(−μt)`، امید `a/λ + (1−a)/μ` است.
- **کای‌دو با ۲ درجهٔ آزادی** همان نمایی با میانگین ۲ است.

**مثال برای هر ترفند:**
- **بی‌حافظه:** `P(X > 1) = ½` ⇐ `P(X ≥ 3) = (½)³ = 1/8`.
- **کمینه:** دو لامپ مستقل، هر کدام با عمر میانگین ۱۰۰۰ ساعت (نرخ `1/1000`). اولین خرابی نمایی با نرخ `2/1000` است، یعنی میانگین ۵۰۰ ساعت.
- **بیشینه:** با `θ = 10`: اولی به‌طور میانگین بعد از `10/2 = 5` خراب می‌شود؛ از آن لحظه، دومی (بی‌حافظه) هنوز به‌طور میانگین ۱۰ وقت دارد ⇐ `15`.
- **آمیزه:** `a = 0.3`، `λ = 1`، `μ = 1/2` ⇐ امید `0.3/1 + 0.7/0.5 = 1.7`.
- **کای‌دو:** `P(χ²₂ > 4) = e^(−4/2) = e⁻² ≈ 0.135`.

### تبدیل متغیر
- **روش تابع توزیع:** `P(Y ≤ y)` را بر حسب X بنویس.
- مثال: اگر `X ~ Beta(θ, 1)` آنگاه `P(−ln X > t) = P(X < e^(−t)) = e^(−θt)`. پس `−ln X` نمایی با نرخ θ است.
- **چگالی متناسب:** اگر `f(x) ∝ g(x)` روی یک بازه، اول ثابت را از `∫ g = 1` پیدا کن.

**مثال:**
- **روش تابع توزیع:** `X ~ U(0, 1)` و `Y = X²`: `P(Y ≤ y) = P(X ≤ √y) = √y`؛ با مشتق، چگالی `1/(2√y)` روی `(0, 1)`.
- **چگالی متناسب:** `f(x) ∝ x` روی `(0, 2)`: `∫₀² x dx = 2` ⇐ `f(x) = x/2`. پس `P(X < 1) = ∫₀¹ x/2 dx = 1/4`.

### تمرین فصل ۲

3. `X ~ U(0, 10)`. `P(X > 7 | X > 5)`؟
4. کمینهٔ دو نمایی مستقل با میانگین‌های ۲ و ۳: میانگینش چقدر است؟

## 🗂 کارت خلاصهٔ فصل ۲
- دوجمله‌ای `np، np(1−p)`؛ هندسی `1/p` (بی‌حافظه)؛ پواسون `λ، λ`؛ رقابت پواسون یا نمایی: `λᵢ/Σλ`.
