## درس ۱: ساختار تابع بازگشتی و ترتیب چاپ

هر تابع بازگشتی دو بخش دارد: **حالت پایه** (توقف) و **فراخوانی روی مسئلهٔ کوچک‌تر**. هر فراخوانی قاب مخصوص خودش را روی **پشتهٔ فراخوانی** دارد، با متغیرهای محلی جداگانه.

**قاعدهٔ طلایی ترتیب چاپ:**
- چاپ **قبل** از فراخوانی ⇐ در مسیر **رفت** چاپ می‌شود (ترتیب نزولی).
- چاپ **بعد** از فراخوانی ⇐ در مسیر **برگشت** چاپ می‌شود (ترتیب صعودی).

```c
void p(int n) { if (n == 0) return; printf("%d ", n); p(n-1); }   // p(3): 3 2 1
void q(int n) { if (n == 0) return; q(n-1); printf("%d ", n); }   // q(3): 1 2 3
void r(int n) { if (n <= 0) return; printf("%d ", n); r(n-2); printf("%d ", n); }
// r(5): 5 3 1 1 3 5   (یک بار در رفت، یک بار در برگشت)
```

## درس ۲: شمردن فراخوانی‌ها و توابع کلاسیک

| تابع | تعداد فراخوانی یا هزینه |
|---|---|
| فاکتوریل `f(n) = n·f(n−1)` | n فراخوانی، `O(n)` |
| فیبوناچی ساده `fib(n) = fib(n−1) + fib(n−2)` | **`2·F(n+1) − 1`** فراخوانی (نمایی). مثلاً `fib(5)`: ۱۵ و `fib(6)`: ۲۵ |
| هانوی | `2ⁿ − 1` حرکت |
| ب.م.م اقلیدسی `gcd(b, a % b)` | `O(log min(a,b))` |
| توان سریع `t = pw(x, n/2)` و بعد `t·t` | `O(log n)` ضرب |
| `h(n) = h(n/2) + h(n/2)` (دو فراخوانی **جدا**) | `2n − 1` فراخوانی برای n توان ۲ |

**روش شمردن:** رابطهٔ «تعداد فراخوانی» را بنویس: `C(n) = 1 + C(زیرمسئله‌ها)`. مثلاً برای فیبوناچی `C(n) = 1 + C(n−1) + C(n−2)` و `C(0) = C(1) = 1`.

⚠️ `pw(x, n/2) * pw(x, n/2)` (دو بار صدا زدن) با `t = pw(x, n/2); t * t` (یک بار) فرق دارد. اولی `O(n)` است و دومی `O(log n)`.

### متغیر static در بازگشت
یک متغیر `static` بین **همهٔ** فراخوانی‌ها مشترک است، نه اینکه هر قاب نسخهٔ خودش را داشته باشد.

## 🗂 کارت خلاصهٔ فصل ۴
- چاپ قبل از فراخوانی: رفت (نزولی). چاپ بعد از فراخوانی: برگشت (صعودی). هر دو: الگوی آینه‌ای.
- تعداد فراخوانی را با `C(n) = 1 + Σ C(زیرمسئله)` بشمار. فیبوناچی: `2F(n+1) − 1`.
- دو بار صدا زدن زیرمسئلهٔ یکسان، هزینه را چند برابر می‌کند. یک بار صدا زدن و ذخیره کردن، `O(log n)` می‌دهد.
- static بین همهٔ قاب‌ها مشترک است. تابع ۹۱: همیشه ۹۱ برای `x ≤ 101`.
