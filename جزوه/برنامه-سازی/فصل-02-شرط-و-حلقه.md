## درس ۱: if و else

### از صفر: دوراهی
تا اینجا برنامه خط‌به‌خط پایین می‌رفت. `if` یک **دوراهی** می‌سازد: «اگر شرط درست است این کار را بکن، وگرنه (else) آن کار را.»
```c
if (شرط)
    دستور_۱;     // فقط اگر شرط درست باشد
else
    دستور_۲;     // فقط اگر شرط نادرست باشد
دستور_۳;         // در هر دو حالت
```

**یادآوری از فصل ۱:** شرط در C یک **عدد** است. صفر یعنی نادرست و **هر عدد غیرصفر** (حتی منفی) یعنی درست.

### آکولاد `{ }` مرز بدنه را تعیین می‌کند
بدون آکولاد، فقط **یک** دستورِ بعد از if جزو آن است، هر قدر هم که تورفتگی چیز دیگری نشان بدهد. کامپایلر تورفتگی را نمی‌بیند.

**مثال:**
```c
int x = 0;
if (x > 0)
    printf("A");
    printf("B");   // این خط جزو if نیست!
```
خروجی `B`. شرط نادرست است و فقط `printf("A")` رد می‌شود؛ خط بعدی همیشه اجرا می‌شود.

### زنجیرهٔ else if: اولین درست برنده است
در زنجیرهٔ `if … else if … else`، شرط‌ها از بالا یکی‌یکی چک می‌شوند و **فقط اولین** شاخه‌ای که درست باشد اجرا می‌شود. بقیه، حتی اگر درست باشند، دیده نمی‌شوند.

**مثال:**
```c
int n = 75;
if (n >= 90)      printf("A");
else if (n >= 70) printf("B");   // اولین شرط درست
else              printf("C");
```
خروجی `B`. شرط `n >= 70` درست بود و زنجیره همان‌جا تمام شد.

### سه قاعدهٔ تستی
1. **هر عدد غیرصفر «درست» است**، حتی عدد منفی. فقط صفر «نادرست» است.
2. **else آویزان:** else به **نزدیک‌ترین if بدون else** می‌چسبد، نه به if ای که تورفتگی نشان می‌دهد.
3. **`;` بعد از if** یعنی بدنهٔ if خالی است. دستور بعدی **همیشه** اجرا می‌شود.

**مثال (قاعدهٔ ۱ و ۳):**
```c
if (-3) printf("A");       // چاپ می‌شود: −3 غیرصفر است
if (0)  printf("B");       // چاپ نمی‌شود
if (5 > 9); printf("C");   // چاپ می‌شود: بدنهٔ if همان ; خالی است
```
خروجی: `AC`.

**مثال (else آویزان):**
```c
int a = 0, b = 1;
if (a)
    if (b) printf("X");
else printf("Y");      // این else مال if (b) است!
printf("Z");
```
خروجی فقط `Z` است. با پرانتزهای واقعی کد این است: `if (a) { if (b) X; else Y; }`. چون a صفر است، کل بلوک داخلی اجرا نمی‌شود.

**روش:** وقتی کد تورفتگی گمراه‌کننده دارد، خودت آکولادها را بر اساس قاعده‌های بالا بگذار و بعد ردگیری کن.

### تمرین درس ۱
```c
// 1
int x = 3;  if (x > 5);  printf("A");
// 2
int y = 0;  if (y = 5) printf("%d", y);
// 3
int z = -2;  printf("%s", z ? "true" : "false");
```

<details>
<summary>جواب‌ها</summary>

1. `A` (بدنهٔ if خالی است)
2. `5` (انتساب، مقدار ۵ دارد که درست است)
3. `true` (منفی هم غیرصفر است)
</details>

## درس ۲: switch

### از صفر: آسانسوری که ترمز ندارد
`switch` مقدار یک متغیر را با برچسب‌های `case` مقایسه می‌کند. با آسانسور تصورش کن: آسانسور در طبقه‌ای که با مقدار جور است **باز می‌شود** و تو وارد می‌شوی، ولی بعد از آن **همهٔ طبقه‌های پایین‌تر** را هم طی می‌کنی، تا وقتی به یک `break` برسی که تو را بیرون می‌اندازد. اسم این رفتار «سقوط» (fall-through) است.

### قواعد
- مقدار switch و برچسب‌های case باید **صحیح یا کاراکتر** و **ثابت** باشند. بازه (مثل `case 1..5`) در C استاندارد نیست.
- **سقوط:** اگر case با `break` تمام نشود، اجرا به case بعدی **ادامه می‌یابد** و دیگر شرط آن چک نمی‌شود.
- `default` یعنی «هیچ case ای جور نشد». می‌تواند هر جایی باشد؛ وقتی اجرا شود، بعد از آن هم سقوط ادامه دارد.

**مثال (قدم‌به‌قدم):**
```c
int k = 2, s = 0;
switch (k) {
    case 1: s += 1;
    case 2: s += 2;          // از اینجا وارد می‌شویم
    case 3: s += 3; break;   // سقوط تا اینجا
    case 4: s += 4;
    default: s += 10;
}
```
1. k برابر ۲ است ⇐ ورود از `case 2`؛ `case 1` اصلاً اجرا نمی‌شود.
2. `s += 2` ⇐ ۲. break نیست ⇐ سقوط به `case 3` (بدون چک کردن ۳).
3. `s += 3` ⇐ ۵. break ⇐ خروج.

جواب `s = 5`. با `k = 4` می‌شد `4 + 10 = 14` (سقوط به default).

**مثال (استفادهٔ مفید از سقوط):**
```c
switch (ch) {
    case 'a': case 'e': case 'i': case 'o': case 'u':
        printf("vowel"); break;
    default:
        printf("consonant");
}
```
با `ch = 'e'` از `case 'e'` وارد می‌شود، تا `printf` سقوط می‌کند و `vowel` چاپ می‌شود. چند case پشت سر هم مثل «یا» عمل می‌کنند.

**روش:** (۱) جای ورود را پیدا کن (case جور، یا default). (۲) از همان‌جا خط‌به‌خط پایین برو و همهٔ دستورها را اجرا کن. (۳) با اولین break یا آخر switch بایست.

### تمرین درس ۲
```c
int k = 7, s = 0;
switch (k) {
    default: s += 10;
    case 1:  s += 1; break;
    case 2:  s += 2;
}
printf("%d", s);
```

<details>
<summary>جواب</summary>

`11`. هیچ case ای جور نیست، پس default اجرا می‌شود. چون break ندارد، به `case 1` سقوط می‌کند و آنجا break می‌خورد.
</details>

## درس ۳: حلقه‌ها

### از صفر: تکرار یک کار
حلقه یعنی «این کار را تا وقتی شرط درست است تکرار کن». سه شکل دارد که در واقع یک کار می‌کنند و فقط **زمان چک کردن شرط** فرقشان است.

### آناتومی حلقهٔ for
`for (شروع; شرط; گام) بدنه;` دقیقاً به این ترتیب اجرا می‌شود:
1. **شروع** فقط **یک بار** اجرا می‌شود.
2. **شرط** چک می‌شود. اگر نادرست بود ⇐ حلقه تمام.
3. **بدنه** اجرا می‌شود.
4. **گام** اجرا می‌شود و برمی‌گردیم به قدم ۲.

**مثال (جدول ردگیری):**
```c
int s = 0, i;
for (i = 1; i <= 4; i++) s += i;
printf("%d %d", s, i);
```

| دور | i (موقع چک شرط) | شرط | s بعد از بدنه |
|---|---|---|---|
| ۱ | 1 | درست | 1 |
| ۲ | 2 | درست | 3 |
| ۳ | 3 | درست | 6 |
| ۴ | 4 | درست | 10 |
| — | 5 | **نادرست** | حلقه تمام |

خروجی `10 5`. ⚠️ بعد از حلقه، i برابر **۵** است، نه ۴: همان مقداری که شرط را نقض کرد.

### سه شکل حلقه
| حلقه | نکته |
|---|---|
| `for (init; cond; step)` | بعد از هر تکرار `step` اجرا می‌شود و بعد `cond` چک می‌شود |
| `while (cond)` | شرط **قبل از** بدنه چک می‌شود ⇐ ممکن است **صفر بار** اجرا شود |
| `do { … } while (cond);` | شرط **بعد از** بدنه چک می‌شود ⇐ **حداقل یک بار** اجرا می‌شود |

**مثال برای هر سطر جدول:**
```c
for (int k = 0; k < 3; k++) printf("%d", k);   // 012
int j = 5;  while (j < 3) printf("X");          // هیچ (صفر بار)
int m = 5;  do printf("Y"); while (m < 3);      // Y (یک بار)
```

**مثال (while با ضرب):** `int k = 1; while (k < 20) k *= 3;` ⇐ k به ترتیب ۱، ۳، ۹، ۲۷. در ۲۷ شرط نادرست می‌شود ⇐ بعد از حلقه `k = 27`.

### تله‌ها
1. **`;` بعد از for:** `for (i = 0; i < 5; i++);` حلقه‌ای با بدنهٔ خالی است. بعد از آن `i == 5` است و دستور بعدی **یک بار** اجرا می‌شود.
2. **شمردن تکرار:** تعداد تکرارهای `for (i = a; i <= b; i += d)` برابر `⌊(b−a)/d⌋ + 1` است.
3. **پسوندی در شرط:** در `while (i++ < 3)` مقایسه با مقدار **قدیمی** i انجام می‌شود، ولی بدنه مقدار **جدید** را می‌بیند.
4. **کاما در for:** `for (i = 0, j = 10; i < j; i += 2, j -= 3)` دو متغیر را هم‌زمان جلو می‌برد.
5. **unsigned:** شرط `u >= 0` برای unsigned همیشه درست است و حلقه بی‌نهایت می‌شود.

**مثال برای تله‌ها:**
- **شمردن:** `for (i = 2; i <= 20; i += 5)` با `i = 2, 7, 12, 17` ⇐ `⌊18/5⌋ + 1 = 4` تکرار؛ بعد از حلقه `i = 22`.
- **کاما:** `for (i = 0, j = 10; i < j; i += 2, j -= 3)` جفت‌های `(0, 10)` و `(2, 7)` را می‌بیند. بعد `(4, 4)` شرط را نقض می‌کند ⇐ ۲ تکرار.
- **unsigned:** `for (unsigned u = 2; u >= 0; u--)` مقادیر `2, 1, 0, 4294967295, 4294967294, …` را می‌گیرد و هیچ‌وقت تمام نمی‌شود.

**روش برای حلقه‌های تودرتو:** برای هر مقدار متغیر بیرونی، حلقهٔ درونی را **کامل** اجرا کن. اگر تعداد دورها خواسته شده، برای هر دور بیرونی تعداد دور درونی را بنویس و جمع بزن (همان روش «شمردن حلقه‌ها» در ساختمان داده).

### تمرین درس ۳
```c
// 1
int i = 10;  do { printf("%d ", i); i++; } while (i < 5);
// 2
int c = 0;  for (i = 1; i <= 100; i += 3) c++;   printf("%d %d", c, i);
// 3
i = 0;  while (i++ < 3) printf("%d ", i);   printf("| %d", i);
// 4
i = 5;  while (i --> 0) printf("%d", i);       // یعنی (i--) > 0
// 5
int c2 = 0;  for (int a = 0; a < 4; a++) for (int b = a; b < 4; b++) c2++;
```

<details>
<summary>جواب‌ها</summary>

1. `10 ` (یک بار اجرا می‌شود، با اینکه شرط از اول نادرست است)
2. `34 103` (`⌊99/3⌋ + 1 = 34`؛ آخرین مقداری که شرط را نقض کرد ۱۰۳ است)
3. `1 2 3 | 4`
4. `43210`
5. `10` (`4 + 3 + 2 + 1`)
</details>

## درس ۴: break و continue

### از صفر: «برو بیرون» و «برو دور بعد»
- `break` یعنی **همین حالا از اتاق بیرون برو**: حلقه (یا switch) تمام می‌شود و اجرا از خط بعد از آن ادامه پیدا می‌کند.
- `continue` یعنی **بقیهٔ این دور را ول کن و برو سراغ دور بعد**: حلقه تمام نمی‌شود.

| دستور | کار |
|---|---|
| `break` | فقط از **درونی‌ترین** حلقه یا switch بیرون می‌رود |
| `continue` | بقیهٔ بدنه را رد می‌کند. در `for` بعدش **step** اجرا می‌شود؛ در `while` مستقیم سراغ شرط می‌رود |

**مثال (هر دو با هم):**
```c
int s = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // زوج‌ها رد می‌شوند
    if (i > 7) break;           // با 9 خارج می‌شویم
    s += i;
}
```
ردگیری: i=1 ⇐ s=1؛ i=2 رد؛ i=3 ⇐ s=4؛ i=4 رد؛ i=5 ⇐ s=9؛ i=6 رد؛ i=7 ⇐ s=16؛ i=8 رد؛ i=9 ⇐ break. جواب `s = 1 + 3 + 5 + 7 = 16`.

⚠️ در `while` اگر `i++` بعد از `continue` باشد، ممکن است اجرا نشود و حلقه بی‌نهایت شود. در `for` این مشکل نیست، چون step در خود for است.

**مثال (continue در while):**
```c
int i = 0;
while (i < 5) {
    if (i == 2) continue;   // i همیشه ۲ می‌ماند: حلقهٔ بی‌نهایت
    i++;
}
```
همین منطق با `for (i = 0; i < 5; i++) { if (i == 2) continue; }` مشکلی ندارد، چون `i++` بخش step است و بعد از continue هم اجرا می‌شود.

⚠️ **break فقط یک لایه:** در دو حلقهٔ تودرتو، break داخل حلقهٔ درونی فقط درونی را تمام می‌کند؛ بیرونی دور بعدش را ادامه می‌دهد. break داخل switch هم فقط از switch بیرون می‌رود، نه از حلقه‌ای که switch در آن است.

### تمرین درس ۴
```c
// 1
int c = 0;
for (int i = 0; i < 3; i++)
    for (int j = 0; j < 3; j++) { if (j == 1) break; c++; }
// 2
int s = 0, i = 0;
while (i < 10) { i++; if (i % 3 == 0) continue; s += i; }
```

<details>
<summary>جواب‌ها</summary>

1. `3`. break فقط حلقهٔ درونی را می‌شکند، پس در هر دور بیرونی فقط `j = 0` شمرده می‌شود.
2. `37`. جمع ۱ تا ۱۰ منهای مضرب‌های ۳: `55 − (3+6+9) = 37`. چون `i++` قبل از continue است، حلقه بی‌نهایت نمی‌شود.
</details>

## 📝 آزمون فصل ۲
> این درس در کنکور ارشد کامپیوتر سؤال سابقه ندارد. پس این ۱۰ تست **تألیفی** هستند و خروجی همه با `gcc` تأیید شده است.

**زمان: ۱۵ دقیقه.** خروجی هر کد چیست؟

**۱.**
```c
int x = 5, y = 10;
if (x > y)
    if (y > 0) x = 1;
else x = 2;
printf("%d", x);
```
۱) `5` ۲) `1` ۳) `2` ۴) خطای کامپایل

**۲.**
```c
int n = 3, r = 0;
switch (n) {
    case 1: r++;
    case 3: r += 3;
    case 5: r += 5;
    default: r += 100;
}
printf("%d", r);
```
۱) `3` ۲) `8` ۳) `108` ۴) `103`

**۳.**
```c
int i = 0, s = 0;
do { s += i; i += 2; } while (i < 0);
printf("%d %d", s, i);
```
۱) `0 0` ۲) `0 2` ۳) `2 2` ۴) حلقه اجرا نمی‌شود و `0 0`

**۴.**
```c
int c = 0;
for (int i = 1; i <= 20; i *= 3) c++;
printf("%d", c);
```
۱) `2` ۲) `3` ۳) `4` ۴) `7`

**۵.**
```c
int s = 0;
for (int i = 0; i < 10; i++) {
    if (i == 2) continue;
    if (i == 6) break;
    s += i;
}
printf("%d", s);
```
۱) `15` ۲) `13` ۳) `19` ۴) `43`

**۶.**
```c
int i = 10;
while (i-- > 7);
printf("%d", i);
```
۱) `7` ۲) `6` ۳) `9` ۴) حلقهٔ بی‌نهایت

**۷.**
```c
int c = 0;
for (int i = 0; i < 5; i++)
    for (int j = 0; j < i; j++)
        if ((i + j) % 2) c++;
printf("%d", c);
```
۱) `4` ۲) `5` ۳) `6` ۴) `10`

**۸.**
```c
int x = -4, r = 0;
switch (x % 3) {
    case 1:  r = 1; break;
    case 2:  r = 2; break;
    case -1: r = 3; break;
    default: r = 4;
}
printf("%d", r);
```
۱) `1` ۲) `2` ۳) `3` ۴) `4`

**۹.**
```c
int i, j, c = 0;
for (i = 0, j = 10; i < j; i += 2, j -= 2) c++;
printf("%d %d %d", c, i, j);
```
۱) `3 6 4` ۲) `2 4 6` ۳) `3 4 6` ۴) `5 10 0`

**۱۰.**
```c
int n = 0;
for (int i = 1; i <= 3; i++)
    for (int j = 1; j <= 3; j++) {
        if (j == i) continue;
        if (j > i) break;
        n += 10 * i + j;
    }
printf("%d", n);
```
۱) `84` ۲) `63` ۳) `21` ۴) `117`

2. از `case 3` وارد می‌شود و تا آخر سقوط می‌کند: `3 + 5 + 100 = 108`.
3. do-while یک بار اجرا می‌شود: `s = 0` و `i = 2`. بعد شرط `2 < 0` نادرست است.

5. `0 + 1 + 3 + 4 + 5 = 13` (۲ رد می‌شود و با ۶ خارج می‌شویم).
6. مقایسه‌ها: `10>7` (i=9)، `9>7` (i=8)، `8>7` (i=7)، `7>7` نادرست ولی کاهش باز هم انجام می‌شود، پس **i=6**.
7. زوج‌های `j < i` با `i + j` فرد: `(1,0)`، `(2,1)`، `(3,0)`، `(3,2)`، `(4,1)`، `(4,3)`. یعنی **۶**.
8. `-4 % 3 = -1` (علامت عدد اول)، پس `case -1` اجرا می‌شود و جواب **۳**.
9. دورها: `(0,10)`، `(2,8)`، `(4,6)` شمرده می‌شوند و با `(6,4)` شرط نقض می‌شود. خروجی `3 6 4`.
10. برای `i=1`: با j=1 رد و با j=2 خارج. برای `i=2`: فقط ۲۱. برای `i=3`: `31 + 32 = 63`. جمع **84**.

## 🗂 کارت خلاصهٔ فصل ۲
- غیرصفر یعنی درست. else به نزدیک‌ترین if بدون else می‌چسبد. `;` بعد از if یا for یعنی بدنهٔ خالی.
- switch بدون break سقوط می‌کند. default هر جا باشد، بعدش هم سقوط ادامه دارد. علامت `%` مهم است.
- do-while حداقل یک بار اجرا می‌شود. تعداد تکرار `⌊(b−a)/d⌋ + 1`. `x++ < n` با مقدار قدیمی مقایسه می‌کند.
- break فقط درونی‌ترین حلقه را می‌شکند. continue در for به step می‌رود و در while به شرط.
