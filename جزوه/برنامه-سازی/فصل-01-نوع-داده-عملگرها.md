## درس ۱: برنامهٔ C از صفر و خواندن خروجی

### این درس برای چیست؟
تقریباً همهٔ تست‌های این درس یک شکل دارند: **«خروجی این کد چیست؟»**. برای جواب دادن لازم نیست برنامه‌نویس حرفه‌ای باشی. کافی است مثل کامپیوتر، خط‌به‌خط جلو بروی و مقدار متغیرها را روی کاغذ نگه داری. این درس همین مهارت را از صفر می‌سازد؛ بقیهٔ کتاب روی آن بنا شده است.

### برنامه از بالا به پایین اجرا می‌شود
```c
#include <stdio.h>          // کتابخانهٔ ورودی و خروجی (برای printf)
int main(void) {            // اجرای برنامه همیشه از main شروع می‌شود
    int x = 5;              // خط ۱
    x = x + 2;              // خط ۲
    printf("%d", x);        // خط ۳: چاپ می‌کند 7
    return 0;
}
```
کامپیوتر خط ۱، بعد خط ۲، بعد خط ۳ را اجرا می‌کند. هیچ خطی «از قبل» یا «هم‌زمان» اجرا نمی‌شود (مگر حلقه و شرط، که در فصل ۲ می‌آیند). در تست‌ها معمولاً فقط بدنهٔ main را می‌بینی.

### متغیر یعنی یک جعبهٔ اسم‌دار در حافظه
`int x = 5;` یعنی: «یک جعبه به اسم x بساز که در آن عدد صحیح (int) جا می‌شود، و ۵ را در آن بگذار.»
- جعبه در هر لحظه **فقط یک مقدار** دارد. مقدار تازه، مقدار قبلی را پاک می‌کند.
- نوع جعبه (int، char، double …) تعیین می‌کند چه چیزی در آن جا می‌شود (درس ۲).

### علامت `=` یعنی «بریز در»، نه «مساوی است»
`x = x + 2` در ریاضی بی‌معنی است، ولی در C یعنی: **اول سمت راست را با مقدار فعلی حساب کن، بعد نتیجه را در جعبهٔ سمت چپ بریز.** با `x = 5`، سمت راست ۷ می‌شود و ۷ در x می‌نشیند.

**قاعده:** در هر خط انتساب، اول **همهٔ** سمت راست با مقدارهای **قبل از** این خط حساب می‌شود، بعد سمت چپ عوض می‌شود.

### چاپ با printf: الگوهای درصد
`printf` متن داخل گیومه را عیناً چاپ می‌کند و هر الگوی `%…` را با مقدار بعدی جایگزین می‌کند، به ترتیب.

| الگو | چه چیزی چاپ می‌کند | مثال | خروجی |
|---|---|---|---|
| `%d` | عدد صحیح | `printf("%d", 7)` | `7` |
| `%c` | یک کاراکتر | `printf("%c", 65)` | `A` |
| `%f` | عدد اعشاری با ۶ رقم اعشار | `printf("%f", 2.5)` | `2.500000` |
| `%.2f` | اعشاری با ۲ رقم اعشار | `printf("%.2f", 2.5)` | `2.50` |
| `%s` | رشته | `printf("%s", "hi")` | `hi` |
| `%u` | عدد صحیح بی‌علامت | `printf("%u", 7u)` | `7` |
| `%zu` | خروجی sizeof | `printf("%zu", sizeof(int))` | `4` |
| `\n` | رفتن به خط بعد | | |

**مثال:** `printf("%d%d", 1, 2);` چاپ می‌کند `12`، نه `1 2`. فاصله فقط وقتی چاپ می‌شود که خودت در گیومه گذاشته باشی: `printf("%d %d", 1, 2)` ⇐ `1 2`.

### مهارت اصلی: جدول ردگیری
برای هر کد، جدولی بکش که هر ستونش یک متغیر است و هر سطرش یک خط کد. بعد از هر خط، مقدار جدید را بنویس.

**مثال (جابه‌جایی بدون متغیر کمکی):**
```c
int a = 3, b = 4;
a = a + b;
b = a - b;
a = a - b;
printf("%d %d", a, b);
```

| خط | a | b | توضیح |
|---|---|---|---|
| `int a = 3, b = 4;` | 3 | 4 | |
| `a = a + b;` | 7 | 4 | `3 + 4` |
| `b = a - b;` | 7 | 3 | `7 − 4`؛ از a **جدید** استفاده شد |
| `a = a - b;` | 4 | 3 | `7 − 3` |

خروجی: `4 3`. یعنی مقدارها جابه‌جا شدند.

⚠️ **تلهٔ جابه‌جایی:** `x = y; y = x;` جابه‌جا **نمی‌کند**. با `x = 2, y = 5`: خط اول x را ۵ می‌کند و ۲ برای همیشه پاک می‌شود؛ خط دوم ۵ را دوباره در y می‌ریزد. خروجی `5 5`. برای جابه‌جایی درست یک جعبهٔ کمکی لازم است: `t = x; x = y; y = t;`.

### تمرین درس ۱
```c
// 1
int p = 10, q = 3;
p = p - q;  q = p + q;
printf("%d %d", p, q);
// 2
printf("%d-%d", 4, 5);
printf("%c%c", 72, 105);
// 3
int k = 1;
k = k * 2;  k = k * 2;  k = k + k;
printf("%d", k);
```

<details>
<summary>جواب‌ها</summary>

1. `7 10`. بعد از خط اول `p = 7`؛ بعد `q = 7 + 3 = 10` (از p جدید استفاده شد).
2. `4-5Hi`. خط دوم بدون فاصله ادامه می‌دهد؛ ۷۲ کد حرف `H` و ۱۰۵ کد حرف `i` است.
3. `8`. مقدار k به ترتیب ۱، ۲، ۴ و بعد `4 + 4 = 8` است.
</details>

## درس ۲: انواع داده

### از صفر: بیت و بایت
حافظه از خانه‌های خیلی کوچکی به اسم **بیت** ساخته شده که هر کدام فقط ۰ یا ۱ است. هشت بیت را یک **بایت** می‌گویند.
- با n بیت دقیقاً `2ⁿ` الگوی مختلف می‌سازی. یک بایت (۸ بیت) ⇐ `2⁸ = 256` مقدار.
- پس هر نوع داده، چون تعداد بایت محدودی دارد، **بازهٔ محدودی** از عددها را جا می‌دهد.

**مثال:** `int` چهار بایت یعنی ۳۲ بیت دارد ⇐ `2³² ≈ 4.3` میلیارد الگو. نصف برای منفی‌ها، نصف برای صفر و مثبت‌ها ⇐ حدود منفی ۲٫۱ میلیارد تا مثبت ۲٫۱ میلیارد.

| نوع | اندازهٔ رایج | نکته |
|---|---|---|
| `char` | ۱ بایت | در واقع یک عدد صحیح کوچک است |
| `short` | ۲ بایت | |
| `int` | ۴ بایت | |
| `long` | ۴ یا ۸ بایت | به سیستم بستگی دارد (لینوکس ۶۴ بیتی: ۸) |
| `float` / `double` | ۴ / ۸ بایت | `0.1` در C به‌طور پیش‌فرض `double` است |

**مثال (خروجی روی لینوکس ۶۴ بیتی):**
```c
printf("%zu %zu %zu %zu", sizeof(char), sizeof(short), sizeof(int), sizeof(double));  // 1 2 4 8
printf("%zu %zu", sizeof(0.1), sizeof(0.1f));                                         // 8 4
```
`sizeof` اندازهٔ هر نوع را بر حسب بایت می‌دهد. `0.1` به‌طور پیش‌فرض double است (۸ بایت)؛ با پسوند `f` می‌شود float (۴ بایت).

### char در واقع عدد است
کامپیوتر فقط عدد می‌فهمد. هر کاراکتر با یک عدد ذخیره می‌شود (جدول **ASCII**). لازم نیست کل جدول را حفظ کنی؛ همین سه بازه کافی است:

| کاراکترها | کدها |
|---|---|
| `'0'` تا `'9'` | ۴۸ تا ۵۷ |
| `'A'` تا `'Z'` | ۶۵ تا ۹۰ |
| `'a'` تا `'z'` | ۹۷ تا ۱۲۲ |

نتیجه‌ها: `'a' − 'A' = 32` (فاصلهٔ حروف بزرگ و کوچک)، `'7' − '0' = 7` (تبدیل رقم کاراکتری به عدد)، و `'z' − 'a' = 25`.

⚠️ `'7'` (کاراکتر، کد ۵۵) با `7` (عدد) فرق دارد. `'7' + 1` برابر ۵۶ است، یعنی کاراکتر `'8'`.

**مثال (char عدد است):**
```c
char c = 'B';
printf("%c %d %c", c + 1, c - 'A', 'G' + 32);   // C 1 g
```
`'B' + 1 = 67` همان `'C'` است؛ `'B' − 'A' = 1` شمارهٔ حرف در الفباست؛ و جمع با ۳۲، حرف بزرگ را کوچک می‌کند. یک عدد را با `%c` چاپ کنی کاراکترش می‌آید و با `%d` خود عدد.

### unsigned: کیلومترشمار ماشین
نوع `unsigned` فقط صفر و مثبت را نگه می‌دارد و وقتی از سقفش رد شود **دور می‌زند**، مثل کیلومترشمار ماشینی که از `999999` به `000000` برمی‌گردد. یعنی حساب به پیمانهٔ `2ⁿ` انجام می‌شود.

**مثال:** `unsigned char` (۸ بیت، بازهٔ ۰ تا ۲۵۵) با مقدار ۲۵۵، بعد از `++` صفر می‌شود. و `unsigned int` صفر، بعد از `−1` بزرگ‌ترین عدد خودش می‌شود: `2³² − 1`.

⚠️ سرریز نوع **باعلامت** (مثل int معمولی) «رفتار تعریف‌نشده» است و تست درست آن را نمی‌پرسد.

### sizeof عبارت داخلش را اجرا نمی‌کند
`sizeof` فقط به **نوع** عبارت نگاه می‌کند و آن را اجرا نمی‌کند. پس بعد از `sizeof(x++)` مقدار x عوض **نمی‌شود**. همچنین در C، `sizeof('A')` برابر ۴ است (چون `'A'` از نوع int است)؛ در C++ برابر ۱ است.

### تمرین درس ۲ (خروجی چیست؟)
```c
// 1
printf("%d %d %d", 'A', 'a' - 'A', '7' - '0');
// 2
unsigned char c = 250;  c = c + 10;  printf("%d", c);
// 3
int x = 7;  size_t s = sizeof(x++);  printf("%zu %d", s, x);
// 4
unsigned int u = 0;  u = u - 1;  printf("%u", u);
```

<details>
<summary>جواب‌ها</summary>

1. `65 32 7`
2. `4` (۲۶۰ به پیمانهٔ ۲۵۶)
3. `4 7` (x اجرا نشد)
4. `4294967295` (یعنی `2³² − 1`)
</details>

## درس ۳: عملگرهای حسابی و افزایشی

### تقسیم صحیح: مثل تقسیم آب‌نبات
وقتی هر دو عدد صحیح‌اند، `/` تقسیم **صحیح** است: فقط سهم کامل هر نفر را می‌دهد و `%` باقی‌ماندهٔ همان تقسیم را.

**مثال:** ۱۷ آب‌نبات بین ۵ نفر: هر نفر ۳ تا (`17/5 = 3`) و ۲ تا می‌ماند (`17%5 = 2`). چک: `3·5 + 2 = 17`.

- تقسیم صحیح **به سمت صفر بریده می‌شود**: `7/2 = 3` و `-7/2 = -3` (نه −۴).
- **علامت `%` همان علامت عدد اول است:** `-7 % 2 = -1` و `7 % -2 = 1`.
- همیشه برقرار است: `a == (a/b)*b + a%b`.

**مثال:**
- با `n = 1234`: `n % 10 = 4` (رقم یکان) و `n / 10 = 123` (حذف رقم یکان). حلقه‌های «جمع ارقام» همین دو کار را تکرار می‌کنند.
- `(-7/2)*2 + (-7%2) = (-3)·2 + (-1) = -7` ✓.

### `++` و `--`: دو کار در یک علامت
`i++` دو کار انجام می‌دهد: (۱) یک **مقدار** به عبارت می‌دهد، و (۲) i را یکی زیاد می‌کند. فرق `i++` و `++i` فقط در این است که کدام مقدار به عبارت داده شود:

| شکل | مقداری که در عبارت استفاده می‌شود | بعد از آن |
|---|---|---|
| `i++` | **مقدار قدیمی** i | i یکی زیاد می‌شود |
| `++i` | **مقدار جدید** (بعد از زیاد شدن) | i زیاد شده است |

**مثال:** `int i = 5; printf("%d ", i++); printf("%d", i);` ⇐ `5 6`. اولی مقدار قدیمی را چاپ کرد؛ تا خط دوم i شش شده بود.

**مثال (هر دو شکل):** `int i = 3; int a = i++; int b = ++i;` ⇐ `a = 3` (مقدار قدیمی)، بعد i چهار می‌شود و `++i` آن را ۵ می‌کند: `b = 5` و `i = 5`.

**مثال:** `int i = 5; int j = i++ + 2;` ⇒ `j = 7` و `i = 6`.

⚠️ **رفتار تعریف‌نشده:** `i = i++;` یا `printf("%d %d", i++, i++);`. تغییر یک متغیر دو بار در یک عبارت، خروجی قطعی ندارد. اگر در تستی دیدی، گزینهٔ «وابسته به کامپایلر / تعریف‌نشده» را در نظر بگیر.

### انتساب ترکیبی
`a += 3` یعنی `a = a + 3`. نکته این است که **کل سمت راست اول حساب می‌شود**: در `a *= 3 + 4` یعنی `a = a * (3+4)`. پس اگر a برابر ۲ باشد، نتیجه ۱۴ است نه ۱۰.

**مثال:** `int x = 2; x -= 1 + 1;` ⇐ `x = 2 − (1 + 1) = 0`، نه `(2 − 1) + 1 = 2`.

### تمرین درس ۳
```c
// 1
printf("%d %d %d %d", -7/2, -7%2, 7%-2, 7/-2);
// 2
int i = 5;  int j = i++ + 2;  int k = ++i * 2;  printf("%d %d %d", i, j, k);
// 3
int a = 17, b = 5;  printf("%d %d", a/b*b + a%b, a % b * 2);
```

<details>
<summary>جواب‌ها</summary>

1. `-3 -1 1 -3`
2. `7 7 14` (بعد از خط دوم i=6 و j=7؛ بعد `++i` آن را ۷ می‌کند و `k = 14`)
3. `17 4` (`*` و `%` هم‌اولویت‌اند و از چپ به راست حساب می‌شوند: `(17%5)*2 = 4`)
</details>

## درس ۴: اولویت، شرکت‌پذیری و اتصال کوتاه

### از صفر: همان قانون ریاضی دبیرستان
در ریاضی یاد گرفتی `2 + 3 × 4 = 14` است، نه ۲۰، چون ضرب **اولویت** دارد. C هم همین کار را می‌کند، فقط عملگرهایش بیشترند. وقتی عبارتی پرانتز ندارد، جدول اولویت می‌گوید کامپیوتر پرانتزها را کجا می‌گذارد.

**مثال:** `2 + 3 * 4` ⇐ ۱۴؛ `(2 + 3) * 4` ⇐ ۲۰؛ `2 * 3 % 4` ⇐ `*` و `%` هم‌اولویت‌اند و از چپ حساب می‌شوند: `6 % 4 = 2`.

**شرکت‌پذیری (جهت):** وقتی دو عملگر هم‌اولویت کنار هم‌اند، جهت تعیین می‌کند کدام اول اجرا شود. بیشترشان از چپ به راست‌اند: `10 - 4 - 3 = (10 − 4) − 3 = 3`. ولی انتساب از راست به چپ است: در `a = b = 5` اول `b = 5` و بعد `a = 5`.

### جدول اولویت (از بالا به پایین؛ فقط آنچه در تست می‌آید)
| اولویت | عملگرها | جهت |
|---|---|---|
| ۱ | `()` `[]` `->` `.` و `++` `--` پسوندی | چپ به راست |
| ۲ | یکانی: `!` `~` `++` `--` `-` `*` `&` `sizeof` `(type)` | **راست به چپ** |
| ۳ | `*` `/` `%` | چپ به راست |
| ۴ | `+` `-` | |
| ۵ | `<<` `>>` | |
| ۶ | `<` `<=` `>` `>=` | |
| ۷ | `==` `!=` | |
| ۸ | `&` | |
| ۹ | `^` | |
| ۱۰ | `\|` | |
| ۱۱ | `&&` | |
| ۱۲ | `\|\|` | |
| ۱۳ | `?:` | **راست به چپ** |
| ۱۴ | `=` `+=` `-=` … | **راست به چپ** |
| ۱۵ | `,` | چپ به راست |

**جملهٔ حفظی:** «یکانی، ضرب، جمع، شیفت، مقایسه، تساوی، بیتی (& ^ |)، منطقی (&& ||)، شرط، انتساب، کاما.»

**یادآوری درست و غلط در C:** نتیجهٔ هر مقایسه یک **عدد** است: ۱ اگر درست و ۰ اگر نادرست. هر عدد غیرصفر «درست» حساب می‌شود.

**روش:** پرانتزهای نامرئی را خودت بگذار، از بالاترین اولویت شروع کن، و بعد از داخل به بیرون حساب کن.

**مثال (ارزیابی قدم‌به‌قدم با جدول):** `int r = 2 + 3 * 4 > 10 && !0;`
1. یکانی: `!0 = 1`.
2. ضرب: `3 * 4 = 12`.
3. جمع: `2 + 12 = 14`.
4. مقایسه: `14 > 10` ⇐ ۱.
5. منطقی: `1 && 1` ⇐ ۱. پس `r = 1`.

### پنج تلهٔ معروف
1. **`a < b < c` بازه را چک نمی‌کند.** اول `a<b` حساب می‌شود که ۰ یا ۱ است، بعد آن عدد با c مقایسه می‌شود. مثال: `5 > 4 > 3` برابر `(1) > 3` یعنی **۰** است.
2. **بیتی از تساوی ضعیف‌تر است:** `x & 3 == 3` یعنی `x & (3==3)` یعنی `x & 1`.
3. **شیفت از جمع ضعیف‌تر است:** `1 << 2 + 1` یعنی `1 << 3` یعنی ۸.
4. **اتصال کوتاه:** در `A && B` اگر A نادرست باشد B **اجرا نمی‌شود**؛ در `A || B` اگر A درست باشد B اجرا نمی‌شود. پس `++` داخل B ممکن است اصلاً اجرا نشود.
5. **`=` به جای `==`:** `if (x = 0)` x را صفر می‌کند و شرط همیشه نادرست است. عملگر کاما هم مقدار **آخرین** عبارت را برمی‌گرداند: `(1, 2, 3)` برابر ۳ است.

### اتصال کوتاه به زبان ساده
وقتی جواب از نیمهٔ اول معلوم شد، کامپیوتر نیمهٔ دوم را **اصلاً نگاه نمی‌کند**. مثل اینکه بخواهی «اگر در باز است **و** چراغ روشن است وارد شو»: اگر در قفل باشد، دیگر سراغ کلید چراغ نمی‌روی.
- `0 && هرچیز` ⇐ ۰، بدون اجرای «هرچیز».
- `1 || هرچیز` ⇐ ۱، بدون اجرای «هرچیز».

**مثال (استفادهٔ درست از اتصال کوتاه):** `if (x != 0 && 10 / x > 1)`. اگر x صفر باشد، شرط اول نادرست است و تقسیم بر صفر اصلاً اجرا نمی‌شود.

### تمرین درس ۴
```c
// 1
int a = 3, b = 4, c = 5;  printf("%d %d", a < b < c, c > b > a);
// 2
int x = 6 & 3 == 3;  printf("%d", x);
// 3
int i = 0, j = 0;
if (i++ && j++) ;   printf("%d %d ", i, j);
if (i++ || j++) ;   printf("%d %d", i, j);
// 4
printf("%d %d", !5 == 0, 1 << 2 + 1);
// 5
int y = 5;  y = y > 3 ? y << 1 : y >> 1;  printf("%d", y);
```

<details>
<summary>جواب‌ها</summary>

1. `1 0`
2. `0` (`6 & 1 = 0`)
3. `1 0 2 0`. در شرط اول، `i++` مقدار ۰ را برمی‌گرداند، پس `j++` اجرا نمی‌شود. در شرط دوم، `i++` مقدار ۱ را برمی‌گرداند، پس باز `j++` اجرا نمی‌شود.
4. `1 8` (`!5 = 0` و `0 == 0` یعنی ۱)
5. `10`
</details>

## درس ۵: تبدیل نوع

### از صفر: نوع جواب را عملوندها تعیین می‌کنند
کامپیوتر برای هر عمل، اول به **نوع دو عدد دو طرفش** نگاه می‌کند و بعد تصمیم می‌گیرد تقسیم صحیح کند یا اعشاری. به متغیری که قرار است جواب در آن ریخته شود **نگاه نمی‌کند**. این بزرگ‌ترین تلهٔ این درس است.

**مثال:** `7/2` ⇐ ۳ (هر دو صحیح)؛ `7/2.0` ⇐ `3.5` (یکی اعشاری)؛ `(double)7/2` ⇐ `3.5` (اول ۷ اعشاری شد)؛ `(double)(7/2)` ⇐ `3.0` (اول تقسیم صحیح انجام شد و ۳ شد، بعد اعشاری).

### قواعد
1. **نوع عملیات از روی عملوندها تعیین می‌شود، نه از روی متغیری که نتیجه در آن ذخیره می‌شود.** در `double d = 5/2;` تقسیم صحیح است و `d = 2.0`.
2. اگر یکی از عملوندها اعشاری باشد، عملیات اعشاری می‌شود: `(double)5/2 = 2.5`، ولی `(double)(5/2) = 2.0`.
3. **تبدیل اعشاری به صحیح به سمت صفر می‌بُرد:** `(int)2.7 = 2` و `(int)-2.7 = -2`. گرد نمی‌کند.
4. **مقایسهٔ signed با unsigned:** عدد signed به unsigned تبدیل می‌شود. پس `-1 < 1u` **نادرست** است، چون −۱ به `4294967295` تبدیل می‌شود (کیلومترشمار درس ۲).
5. **`float` با `double`:** `float f = 0.1;` و بعد `f == 0.1` نادرست است، چون `0.1` در float و double با دقت متفاوت ذخیره می‌شود.

**مثال (میانگین):**
```c
int s = 7, n = 2;
double avg  = (double)s / n;   // 3.5
double avg2 = s / n;           // 3.0  (تقسیم صحیح، بعد تبدیل)
int k = 3.99;                  // 3    (بریدن، نه گرد کردن)
```

### تمرین درس ۵
```c
// 1
double d = 5/2;  printf("%f %.1f %.1f", d, (double)5/2, (double)(5/2));
// 2
printf("%s", (-1 < 1u) ? "yes" : "no");
// 3
int x = 'a' + 1.5;  printf("%d", x);
// 4
printf("%.1f %.1f", 3/2*2.0, 3*2.0/2);
// 5
float f = 0.1;  printf("%s", f == 0.1 ? "equal" : "not equal");
```

<details>
<summary>جواب‌ها</summary>

1. `2.000000 2.5 2.0`
2. `no`
3. `98` (`97 + 1.5 = 98.5` که بریده می‌شود)
4. `2.0 3.0`. در اولی `3/2` اول حساب می‌شود و ۱ است. در دومی `3*2.0 = 6.0` و بعد تقسیم بر ۲.
5. `not equal`
</details>

### خلاصهٔ روش حل تست‌های «خروجی چیست؟»
1. جدول ردگیری بکش: یک ستون برای هر متغیر.
2. هر خط را با مقدارهای **فعلی** حساب کن؛ اول سمت راست، بعد انتساب.
3. هر جا پرانتز نبود، با جدول اولویت پرانتز بگذار.
4. سه چیز را همیشه چک کن: تقسیم صحیح یا اعشاری؟ `i++` یا `++i`؟ اتصال کوتاه جلوی اجرای چیزی را گرفته؟
5. خروجی را دقیقاً مثل printf بنویس: فاصله‌ها، خط‌ها، و الگوهای `%`.

## 📝 آزمون فصل ۱
> این درس در کنکور ارشد کامپیوتر سؤال سابقه ندارد. پس این ۱۰ تست **تألیفی** هستند و در قالب تست کنکور نوشته شده‌اند. خروجی همهٔ کدها با `gcc` اجرا و تأیید شده است.

**زمان: ۱۵ دقیقه.** خروجی هر کد چیست؟

**۱.**
```c
int a = 10, b = 3;
printf("%d %d", a / b, -a % b);
```
۱) `3 1` ۲) `3 -1` ۳) `4 -1` ۴) `3 2`

**۲.**
```c
int x = 5, y = 0;
if (x > 3 || ++y) x++;
printf("%d %d", x, y);
```
۱) `6 1` ۲) `6 0` ۳) `5 1` ۴) `5 0`

**۳.**
```c
int a = 1, b = 2, c = 3;
printf("%d", a < b < c == c > b > a);
```
۱) `0` ۲) `1` ۳) `3` ۴) خطای کامپایل

**۴.**
```c
unsigned int u = 1;
int i = -1;
printf("%s", i < u ? "less" : "not less");
```
۱) `less` ۲) `not less` ۳) خطای کامپایل ۴) رفتار تعریف‌نشده

**۵.**
```c
double d = 7 / 2 + 7 / 2.0;
printf("%.1f", d);
```
۱) `7.0` ۲) `6.5` ۳) `6.0` ۴) `7.5`

**۶.**
```c
int x = 0x0F;
printf("%d", x & 0x3C | 1 << 4);
```
۱) `28` ۲) `12` ۳) `208` ۴) `13`

**۷.** (فرض: `int` ۴ بایتی)
```c
int i = 3;
int j = sizeof(i++) + i;
printf("%d", j);
```
۱) `7` ۲) `8` ۳) `4` ۴) خطای کامپایل

**۸.**
```c
char c = 'B';
c = c + ('a' - 'A');
printf("%c %d", c, c - 'a');
```
۱) `b 1` ۲) `B 1` ۳) `b 33` ۴) `b 0`

**۹.**
```c
int a = 5, b;
b = (a++, a * 2);
printf("%d %d", a, b);
```
۱) `6 12` ۲) `5 10` ۳) `6 10` ۴) `5 12`

**۱۰.**
```c
int k = 0;
int r = (k = 3) && (k = 0) || (k = 5);
printf("%d %d", r, k);
```
۱) `1 5` ۲) `0 0` ۳) `1 3` ۴) `0 5`

<details>
<summary>جواب‌ها و راه‌حل</summary>

| سؤال | ۱ | ۲ | ۳ | ۴ | ۵ | ۶ | ۷ | ۸ | ۹ | ۱۰ |
|---|---|---|---|---|---|---|---|---|---|---|
| جواب | ۲ | ۲ | ۱ | ۲ | ۲ | ۱ | ۱ | ۱ | ۱ | ۱ |

1. `10/3 = 3`. منفی یکانی اولویت بالاتری دارد، پس `-a % b` یعنی `(-10) % 3` که برابر `-1` است (علامت عدد اول).
2. `x > 3` درست است، پس `++y` به خاطر اتصال کوتاه اجرا نمی‌شود. خروجی `6 0`.
3. مقایسه‌ها از `==` قوی‌ترند. سمت چپ: `(1<2)=1` و `1<3` می‌شود ۱. سمت راست: `(3>2)=1` و `1>1` می‌شود ۰. پس `1 == 0` یعنی **۰**.
4. −۱ به unsigned تبدیل می‌شود و `4294967295` می‌شود، که از ۱ بزرگ‌تر است. خروجی `not less`. این رفتار کاملاً تعریف‌شده است.
5. `7/2 = 3` (صحیح) و `7/2.0 = 3.5`. جمع **6.5**.
6. ترتیب اولویت: شیفت، بعد `&`، بعد `|`. `1<<4 = 16` و `0x0F & 0x3C = 0x0C = 12`. پس `12 | 16 = 28`.
7. `sizeof` اجرا نمی‌کند، پس i همان ۳ می‌ماند. جواب `4 + 3 = 7`.
8. `'B' + 32 = 'b'` و `'b' − 'a' = 1`.
9. کاما نقطهٔ ترتیب است: اول `a++` اجرا می‌شود و a می‌شود ۶، بعد `b = 6*2 = 12`.
10. `&&` از `||` قوی‌تر است. `(k=3)` مقدار ۳ (درست) دارد، `(k=0)` مقدار ۰ (نادرست)، پس `&&` می‌شود ۰. بعد `(k=5)` اجرا می‌شود که درست است، پس `r = 1` و `k = 5`. چون `&&` و `||` نقطهٔ ترتیب دارند، رفتار تعریف‌شده است.
</details>

## 🗂 کارت خلاصهٔ فصل ۱
- `char` عدد است: A=65، a=97، 0=48. `unsigned` دور می‌زند. `sizeof` اجرا نمی‌کند.
- `/` صحیح به سمت صفر می‌بُرد. علامت `%` همان علامت عدد اول است.
- `i++` اول مقدار قدیمی را می‌دهد. دو بار تغییر یک متغیر در یک عبارت رفتار تعریف‌نشده است.
- اولویت: یکانی > `* / %` > `+ -` > شیفت > مقایسه > تساوی > `&` > `^` > `|` > `&&` > `||` > `?:` > `=` > `,`
- `a<b<c` بازه نیست. `&&` و `||` اتصال کوتاه دارند.
- نوع عملیات را عملوندها تعیین می‌کنند. signed در مقایسه با unsigned تبدیل می‌شود. float را با `==` مقایسه نکن.
