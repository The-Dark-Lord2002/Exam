## هر کتاب چه دارد؟
| بخش | توضیح |
|---|---|
| ✏️ **مثال** | مسئلهٔ حل‌شده برای دیدن قاعده در عمل |
| ⚠️ **تلهٔ تستی** | جایی که طراح کنکور بیشتر از همه غافلگیر می‌کند |
| 💡 **نکته و قاعده** | میان‌بُرهایی که سر جلسه وقت می‌خرند |
| ✍️ **تمرین** | آخر هر درس؛ پاسخ‌ها در پاسخ‌نامهٔ آخر همان فصل (با شمارهٔ صفحه) |
| 📝 **آزمون فصل** | سؤال‌های کنکور ارشد کامپیوتر ۱۳۹۸ تا ۱۴۰۴ با **کلید رسمی سازمان سنجش** |
| 🗂️ **کارت خلاصه** | چکیدهٔ یک‌صفحه‌ای هر فصل برای مرور شب قبل از آزمون |

**چرخهٔ مطالعهٔ هر فصل (۹۰ دقیقه):** پیش‌آزمون ۵ دقیقه ← درس‌نامه ۳۵ ← تمرین ۳۰ ← آزمون فصل ۱۵+ ← دفتر خطا ۵.
